# kotoba-shokunin

A **shokunin lane** — an expert agent for one domain, minted and trained
under the [shokunin skill](https://github.com/VeigaPunk/shokunin).

**Domain:** prompt & skill craft — scopes SKILL.md/AGENTS.md quality, trigger fidelity

**Wiki:** [Devin wiki](https://app.devin.ai/org/veigapunk/wiki/VeigaPunk/kotoba-shokunin?branch=master)

## What's here

- `SKILL.md` — the distilled expertise: decision tables, error patterns,
  fidelity checklists, cited sources
- `PROVINCE.md` — the owned domain boundary: Core, Frontier, Adjacent, refusals
- `corpus/` — sourced knowledge, per-round lessons, `QUALITY.md` (admission
  bar) and `SOURCES.md` (where the lane learns)
