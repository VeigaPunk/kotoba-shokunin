## Task

Critic on D2/D3 (claim D: make `extract_boxes` skip fenced regions). Question: does skipping fenced regions break a legit case — a box inside a fence that *should* count — and is the patch minimal? Pick the landing diff.

## Findings

**No legit case is broken.** CommonMark makes fenced content literal code, so a box inside a fence is never a live box. Empirically: zero fixture and zero live boxes/near-misses sit inside a fence; all 76 files extract identically.

**M1 closed.** Silent neutralization (box swapped for an identical fenced decoy, parity kept at exit 0) is reproduced on HEAD and fails on the patch, naming the orphaned map entry.

**Hunk 1 also fixes a latent section bug.** `# a comment line` inside a ```` ```bash ```` block was parsed as a heading (`command-skip-list` fixture, line 15); a box after such a fence was attributed to the comment. Patched build attributes it correctly. No fixture observes this because none puts a box after that fence.

**Hunk 2 is required, but not for the decoy class.** Without it a box followed by an indented fence absorbs the fence text into its `text`, silently changing its sha256 (`probe/absorb.md`: `'box before an indented fence ```text prose inside '` → `'box before an indented fence ```text'`). Keep it.

**Short-closer guard is a precondition, not an extra.** `fenced_regions` accepts a 3-tick line as closer of a 4-tick fence, which CommonMark forbids. Unguarded, `m1c` leaves the decoy counted *and* swallows a later real box — a new silent pass. The `len(...) >= len(fence_len)` guard closes it and changes nothing on the 76 files.

## Defects

1. **(residual, unclaimed)** Indented code blocks are not skipped: a `    - [ ] decoy` at top level still counts (`probe/indented.md`, HEAD and patched both `n=2`). The claim is fenced-only; this is the next decoy class. No live or fixture instance.
2. **(precondition)** Short-closer pairing in `fenced_regions` — see above; ship the guard with hunk 1 or the patch opens a new hole.
3. **(latent, fixed by hunk 1)** Heading-inside-fence section corruption (`command-skip-list:15`).
4. **(limit, not a defect)** An unclosed fence swallows every later box → `no checklist boxes in target file`, a loud FAIL, not a silent pass.

## Limits

Landing diff is 3 hunks in `verifiers/verify_skill_checklist.py` only (`/dev/shm/d4/landing.diff`); no fixture added, so the decoy class has no regression pin — recommend a `map-fenced-decoy` fixture pair in a later round. `check_substrate_pins` needs `TMPDIR=/dev/shm` (default TMPDIR is full); `verify_corpus_independent` self-test fails only from a non-repo cwd (`git ls-files`). No repo file other than this fragment was written.
