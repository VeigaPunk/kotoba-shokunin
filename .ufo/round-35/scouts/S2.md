## Findings
- Live state is green and exact: 3/3 pins hold, self-test 62, floors `pins observed=62 floor=62`, zero headroom.
- Ladder behaves as documented on every probe I ran: `PIN_ABSENT` 1, `VACUOUS` 1 (null/int/empty/list), `UNREADABLE` 2, `BAD_PIN` 3 (bool, null, empty string, 63/65 hex, 10-digit dot fraction), mis-cased/padded/NUL keys 2, no traceback anywhere.
- **Comma-fraction mtime pin is mis-parsed.** `FRAC_RE = r"\.(\d+)"` (`:110`) matches only a dot, but `datetime.fromisoformat` accepts ISO's comma form. `2026-10-16T05:15:11,226207850-03:00` → fraction 0, `tolerance_ns=999999999` (`:150,:155`): a ±1 s window instead of 0. Measured: comma pin 1.0 s off live → exit 0 PASS; same value with a dot → exit 1 DRIFT. The exact-instant comma pin also passes but reports `delta 226207850 ns`, so the PASS line's delta is wrong by 226 ms.
- **Duplicate JSON keys are silent last-wins** (`:320` `json.loads`): `{bad sha, good sha}` → exit 0 `OK 3/3`; reversed → exit 1 DRIFT.
- Coverage is hard-wired: `BINARIES` (`:61`) and `EXPECTED_PINS` (`:72`) name omp+opencode only. `cursor-agent`, `devin`, `kimi`, `grok` all resolve on this host; adding `cursor_binary_sha256`/`devin_binary_sha256`/`kimi_binary_sha256` → exit 2 UNSUPPORTED, so a rebuild of any of the four is invisible to every gate.
- Coarse pins behave as designed and are reported: no fraction → `tolerance 999999999 ns` each side; 6-digit → 999 ns.

## Defects
1. **HIGH — comma-form mtime pin silently widens the window to ±1 s** (`:110` FRAC_RE vs `:150/:156`). Reachable on any future re-pin written in ISO's comma form; live pin is dot-form so today's green is unaffected. Self-test never exercises comma (0 occurrences), so no assertion would catch it.
2. **MEDIUM — duplicate `measured_against` key is last-wins, never reported** (`:320`). A bad-then-good duplicate reads green; good-then-bad reads DRIFT. Same class as round-34 M7 defect 7 (floors registry), unfixed here.
3. **MEDIUM — pin coverage is two substrates of six.** Four CLIs on this host are unpinned and cannot be pinned without a code edit (exit 2 UNSUPPORTED). The corpus "Honest ceiling" names unpinned *state* (caches, log grammar) but not unpinned *binaries*.
4. **LOW — stale docs.** `SCORECARD.md:159` still prints floors `…88…82…51` and `SCORECARD.md:158` "51 assertions" (live 108/87/62); `corpus/knowledge/substrate-pin-guard-round23.md:34` says 51 assertions; `:36` credits `tripwire.bin` as an assertion though no code path references `fixtures/pins/` (evidence-only since r28) — `git grep tripwire` hits docs only.
