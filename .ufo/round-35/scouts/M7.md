## Findings
- Live guard is green and exact: zero headroom on all six floors, so any dropped assertion flips it. Deletion detection names instrument + observed-vs-floor, exit 1, never crashes on a missing/unreadable script.
- Timeout (r30 M5 class) and the hang path are closed; registry drift is caught **as long as only one table is edited**.
- Determinism holds: 12 consecutive runs on a drifted copy, 0 FAILs; earlier transient `observed=0` readings on that copy did not reproduce (copy artifact, not a guard flake).

## Defects
1. **HIGH (self-guard vacuity, confirmed).** `registry_drift()` compares two tables **in the same file** (`:26-33` vs `:36-49`). A coordinated edit — delete the row from both, or lower both floors — exits 0 and silently stops rerunning that instrument. Proven twice (5-row exit 0; `floor=80` exit 0). This is the r30 S6 class one level up: the guard's own floor/registry has no external anchor.
2. **MEDIUM (no path binding).** Rows carry script paths, but nothing pins the row to its instrument's identity: `pins` -> `verify_skill_checklist.py` with floor 62 yields `PASS pins observed=1504 floor=62`, exit 0. A higher count passes `>= floor`; only a lower-count instrument trips it. No sha pin exists for any verifier.
3. **MEDIUM (docstring wrong).** `:8-10` claims exit 2 for "could not run or its output was unparseable". Behavior: unparseable -> 1, missing/unreadable/crashing -> 1; only timeout and registry drift -> 2. Same defect scout S6 named at r30; still unfixed, and `:6-8` still says `@ round 29` while floors are r33 values.
4. **MEDIUM (stale docs).** `SCORECARD.md:159` (capability row) still prints floors `10/88/52/82/1504/51` and round 27; code is `10/108/52/87/1504/62`. `SKILL.md` names no floors guard at all.
5. **LOW (live-mode blind spot, pre-existing).** The guard only ever runs `--self-test`; a live-only regression (`SKILL.md` box plant -> live checklist exit 1) leaves the guard at 6 PASS exit 0. No runner, hook, or CI invokes the guard (grep: zero non-prose callers).
6. **LOW (no `--self-test`).** `--self-test` is rejected by argparse (exit 2), so the guard cannot be guarded by an aggregate of itself.
7. **LOW (no duplicate-key check).** A duplicated `INSTRUMENTS` key is silently last-wins (exit 0); `EXPECTED_INSTRUMENTS` uses dict-literal dedupe with no `object_pairs_hook`.
8. **LOW (bad `--repo`).** Non-directory `--repo` produces a raw traceback (exit 1) rather than the documented exit 2.
