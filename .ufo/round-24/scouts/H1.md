## Findings

**Mechanism (≤5 lines):**
1. `self_test()`'s `run()` (:1341-1348) builds fixture argv with `--skill`/`--map` but **no `--repo`**.
2. `main()` (:1752-1753) then computes `repo = find_repo_root(skill_path)`.
3. `find_repo_root` (:386-392) returns the nearest ancestor with a `.git` marker, **else the file's own directory**.
4. In a git-archive export no `.git` exists anywhere, so `repo` = `verifiers/fixtures/checklist/<case>/` for every case.
5. Every repo-rooted check then resolves against that fixture dir: `governance.citation_resolves` reads `LOG.md`/`SCORECARD.md` there (absent → FAIL), and `citation_resolves`/`command_binary_resolves` resolve `corpus/…`/`verifiers/…` tokens from it (absent → FAIL) — 108 assertions, exit 1.

Root cause is **argv construction, not `find_repo_root`**: the fallback is correct for a foreign target (the `foreign-no-map` case deliberately exercises it), but the self-test must pin the repo explicitly so its green is a property of the *script*, not of the checkout's `.git` presence or the cwd. Confirmed by the direct probe: adding `--repo` alone flips `clean` from exit 1 to exit 0 with `N/A governance.citation_resolves`.

**Fix shape (proven on /tmp, 2 lines):** add `--repo str(DEFAULT_REPO)` to both fixture argv sites. `DEFAULT_REPO` (:269) = `Path(__file__).resolve().parent.parent` — script-relative, so it is hermetic by construction. Result: export self-test 108/1504 → **0/1504, exit 0**, from any cwd; assertion count stays 1504; live gate and live self-test stdout byte-identical (empty `diff`); clone still 0/1504; red probes still flip; a perturbed fixture still fails.

**Attribution detail:** 79 of 108 failures are `governance.citation_resolves` (each case also emits a paired `N/A-allowed` assertion), 79 `trigger.citation_resolves`, 79 `trigger.command_binary_resolves`, plus 29 wrong-exit assertions. The `foreign-no-map` case is a *second* argv site (:1555-1556) — fixing only `run()` leaves exactly 1 failure, so both sites must be patched for unanimity.
