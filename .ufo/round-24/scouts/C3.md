## Findings

### F1 — Window state at HEAD: **0**, reset point = round 23

The `## Capabilities` table holds exactly **1** data row — `substrate-pin guard`,
first-working round **23** (`SCORECARD.md:116`, cmd 16). `SCORECARD.md:40` and
`LOG.md:1233` both record "stagnation window resets to 0" (cmd 4). So as of
`b889e78` the window stands at **0**; round 23 is the **reset point**.

Round 24's own declaration agrees: `.ufo/round-24/claims.json:48` — "Window reset
at round 23, so no nudge pressure." Both round-24 claims (E freshness, H
operability) are **ordinary axis claims, not capability acquisitions** (verified:
neither claim text declares a capability), so a round 24 that lands E and H is a
capability-free round.

### F2 — The convention (recorded, precedent-based; `AXES.md` does not define it)

`AXES.md:66-73` states the nudge condition but never defines the window boundary —
which round opens a window, whether the reset round counts. The convention this
lane should adopt, drafted in round 23 and reproducible from fleet precedent:

- **The capability-bearing round is the reset point and does not count** (window
  = 0 at its end).
- **The next dispatched lane-round opens the new window at 1/N**, if it enters no
  capability row.
- **The window completes at the end of the Nth counted round**, and the waiver
  applies **from the round after completion**.

Precedent (`kaidoku-shokunin/SCORECARD.md`, cmds 19-21): `:634` "window resets
from here" is declared at luna-round-10; `:638` the *following* round is "the
first round of the reset stagnation window"; `:1272` that arc's round 10 reads
"Round 10 of the reset window (10/10 — window complete)". Exactly the reset-round-
does-not-count rule.

Source of the convention in this lane: `.ufo/round-23/scouts/C2.md:213` (the
paste-ready F5 line) and `:198-201`. It is **committed** (cmd 15) but only inside a
scout fragment — see D1.

### F3 — When would it next fire if no capability lands? (the arithmetic)

Under F2, with round 24 entering no capability row:

| Round | Counted? | Window |
|---|---|---|
| 23 (capability row #1 entered) | reset point — **not counted** | 0 |
| 24 | 1st | **1/3** |
| 25 | 2nd | 2/3 |
| 26 | 3rd | **3/3 — complete** |
| 27 | — | **first nudge-eligible round** |

Reproduced by a scripted tally (integer arithmetic, no hand count):

```
saturation line      : 10.0
owned axes at HEAD   : depth 9.0 / consistency-calibration 10.0
condition (i) axes>=line : False  (depth 9.0 < 10.0 => FAIL)
window at end of r23 : 0 (reset point)
  round 24: 1/3
  round 25: 2/3
  round 26: 3/3
window complete at end of round 26 (3/3)
first nudge-eligible round : 27
```

**The window alone never fires it.** `AXES.md:68-70` requires *both* conditions:
(i) every owned axis ≥ the saturation line, and (ii) no capability within the
window. Condition (i) is **false at HEAD** — depth 9 < line 10.0, and the lane's
own §Saturation says so ("depth sits below the line, so **the nudge is dormant**",
`SCORECARD.md:133-134`). So the strict answer is: **condition (ii) would be
satisfied at the end of round 26, but the nudge still would not fire** — a depth
band-10 move must close condition (i) first. Reported this way rather than as
"fires at round 27", which would be the round-22 overclaim class (D3).

   rounds since the reset" without reading a scout file. Severity: moderate
   (record-completeness). Confirms and sharpens round-23 scout C2 defect 2.
2. **`SCORECARD.md:40` and `LOG.md:1233` are not the contract field.** Both carry
   the reset ("resets to 0") but sit in `## planned` (cmd 17) and the Round-23 LOG

   boundary convention of F2. The next reader gets the *number* without the *rule*.

   sentence (`:137-138`) counts "consecutive dispatched lane-rounds in which no
   capability row enters the table"; the rationale (`:141-143`) says "the window

   verdict (provider failure — a live class: round 23's keys 3-5 `402`) is neither
   cleanly. Carried from round-23 scout C2 defect 5; still true at HEAD (cmd 3, 10).
4. **`LOG.md:1224` — "if not, the nudge fires for round 24" overclaims condition (i).**
   Committed at HEAD (cmd 13). `AXES.md:68` requires every owned axis ≥ the line;
   depth 9 < 10.0, so the window's completion alone cannot fire the nudge. This is
   the same overclaim round-23 scout C2 defect 1 named; it remains uncorrected in
   the LOG text (the round-23 entry corrected only the outcome, not this sentence).

   unmarked.** "the clock starts at the declaration round" (round 21) describes the
