## Findings

**The defect (agreed by all lanes, independently re-derived).**
`find_repo_root()` (`verifiers/verify_skill_checklist.py:386-392`) returns the
nearest ancestor carrying a `.git` marker, **else the target file's own
directory** (`:392 return cur`). The self-test's shared runner `run()`
(`:1342-1343`) builds fixture argv with `--skill`/`--map` and **no `--repo`**,
and the `foreign-no-map` extra (`:1556`) calls `run_capture` directly with no
`--repo` either. In a `.git`-less export `main()` (`:1752-1753`) falls into the
else-branch, so `repo` := the fixture's own dir. Then `governance_enabled`
(`:1756`) is True (the fixture SKILL.md *is* that dir's SKILL.md), so
`check_governance_citations` hunts `LOG.md`/`SCORECARD.md` inside the fixture
dir → unreadable → FAIL; and every `corpus/…`/`verifiers/…` token re-bases
onto the fixture dir → FAIL. 108 assertions, exit 1. A checkout masks it
because `.git` is found at the true root.

   self-test byte-identical in both `.git`-present and `.git`-less layouts;
   foreign-target behavior unchanged; assertion total stays 1504; non-vacuity
