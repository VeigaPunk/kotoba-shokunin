## Findings

1. **Byte-invariance HOLDS for shapes A and C on every surface I could
   reach.** Live gate (all 10 lines) and normal-mode `--self-test` are
   byte-identical to pristine in the mirrored env — identical sha256 for all
   four outputs, in both plain and `--json` mode, and identical on the
   foreign-target and fixture-as-target runs. Both shapes also deliver the
   claimed effect: export `--self-test` 108/1504 rc=1 → 0/1504 rc=0,
   cwd-independent, assertion count unchanged at 1504, and all six red probes
   still flip rc=1.

2. **Shape B (the `find_repo_root` fallback) FAILS the invariance test.** It
   changes live behavior outside the self-test: for a foreign skill under a
   `.git`-less tree, `governance.citation_resolves` flips `FAIL`→`N/A` and the
   exit code flips 1→0. That is the instrument's only remaining red for such a
   target, so B converts a fail-closed foreign check into a silent pass — the
   opposite of the fail-closed convention the file documents (`:249` "`evaluated
   0` is a FAIL"). B is the shape that most directly matches the claim's stated
   locus (`:386-392`), so if B is the intended landing, claim H's "live behavior
   byte-invariant" sub-clause is **false** and the claim must not land as
   written.

3. **Shape C is byte-invariant on the `.git`-ful live path but narrows the
   `.git`-less behavior** for a fixture-path target (`FAIL`→`N/A`). Its guard is
   scoped to `FIXTURES` parents, so the repo's own live path and any non-fixture
   foreign target are untouched (verified: foreign rc=1 both pristine and C).
   The divergence is confined to running the gate on a fixture inside an export
   — a shape the self-test itself never uses after patching (it passes `--repo`
   explicitly under A). C therefore satisfies "live behavior byte-invariant"
   literally, but its blast radius is larger than A's.

4. **A is the only shape that is byte-invariant with zero behavioral delta
   anywhere.** It touches argv construction inside `self_test()` only; the
   `main()` resolution path (`find_repo_root`, `governance_enabled`, default
   box-map path) is untouched, so every non-self-test invocation — repo gate,
   foreign target, fixture target, `--json`, any cwd — is bit-for-bit pristine.
   This corroborates H1's derivation (root cause is argv construction, not
   `find_repo_root`) and contradicts the claim text's stated locus.

5. **All three shapes share the same red-probe and count properties**, so the
   choice between them is decided purely by blast radius, not by efficacy. A
   wins that comparison; C is second; B is disqualified.
