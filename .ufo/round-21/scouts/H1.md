## Defects named

1. **`.gitignore:1` — bytecode ignore rules lost; cleanup non-durable.** Path `gitignore` (repo root, 1 line: `.ufo/interactive-sessions/`). Evidence: `git show c8b53ac -- .gitignore` removes `__pycache__/` and `*.pyc` while the same commit adds two `.pyc` blobs; `4e92f36` untracks them but does not restore the rules; `git check-ignore -v` exits 1 for all three `.pyc` at `verifiers/__pycache__/` (mtimes 2026-10-19 00:46). Effect: any verifier run leaves 3 untracked files, so the HEAD cleanup does not hold. Fix (for a later round, not done here): restore `__pycache__/` and `*.pyc` to `.gitignore`.

2. **Stale `origin/master` tracking ref → `git status -sb` misreports the push relationship.** Path `.git/refs/remotes/origin/master` (= `c8b53ac`, committer date 2026-10-17 00:29:04 -0300) vs true remote `refs/heads/master` = `74fc0f1` (cmd 38/39/42, object absent locally, cmd 31). Evidence: `git rev-list --left-right --count origin/master...HEAD` = `0 1` (reports ahead-1) while the clone shows `c8b53ac..74fc0f1` = 2 commits and `4e92f36` absent from the remote (cmd 47). Effect: the round's "ahead-1, unpushed" claim is true only against the stale ref; the true relation is diverged and a plain push is rejected non-fast-forward. Also `.git/packed-refs` retains a superseded `fad752b` entry (cmd 34). Fix: `git fetch` before any push decision (not run here — it would write to the live `.git`).

3. **Identity held by a repo-local override only; global config is `ci <ci@local>`.** Evidence: `git config --global --get user.name` = `ci`, `--get user.email` = `ci@local`; repo-local = `kotoba-shokunin` / `kotoba@shokunin.local`; history already contains 2 commits with the leaked identity, `2193667` and `1fbf02b` (`HOURS.md` add + revert). Not named in `LOG.md` or `SCORECARD.md` (cmd 58, exit 1). Effect: any commit made from a shell outside this repo's local config, or after the local override is lost, silently leaves the lane identity. Fix: export `GIT_AUTHOR_*`/`GIT_COMMITTER_*` in the lane wrapper, or audit commits before push.

4. **Remote ref clutter: 8 unmerged `cursor/*` readme branches plus a merged `devin/wiki-link` branch.** Evidence: `git ls-remote origin` (cmd 40) and clone `git branch -r --no-merged 74fc0f1` (cmd 49) + per-branch `--left-right --count` (cmd 50) showing each `cursor/*` at `2 behind / 1 ahead`, `devin/wiki-link` at `1 behind / 0 ahead`. Effect: the remote carries 9 stale branches that are invisible locally (cmd 36/37 list only `origin/master`), so any future fetch surfaces them as unexplained refs. Fix: delete merged/stale branches at the remote (operator action; not performed here).

5. **Remote still tracks the two `.pyc` blobs that local `4e92f36` removes.** Evidence: clone `git ls-files | grep -c -E 'pyc|__pycache__'` = 2 (cmd 51), while local = 0 (cmd 21, exit 1).
