## Findings

1. **Red probe green-lit.** The governance predicate fails closed exactly as
   round 17 recorded: one unquoted dead repo-rooted token in `SCORECARD.md`
   flips the check PASS→FAIL, names the file and line, counts the token
   (`evaluated` 154→155) and the process exit 0→1. Running the whole suite
   post-plant changes nothing else, so the FAIL is attributable to the planted
   token alone.
2. **Every documented exclusion and boundary reproduces on a live plant**, not
   only in fixtures: same-line double-quote enclosure (B, I) excludes and is
   *counted* (9 quoted), the ellipsis and literal-`round-N` schematics (D, E)
   are excluded and counted (4 schematic), a same-line quote that does **not**
   enclose the token does not suppress it (C), a quote carried across lines
   does not suppress it (G) — the round-17 rejected design stays rejected — and
   a resolving token still counts (H). No over- or under-suppression observed
   in 9/9 controls.
3. **Live state at HEAD.** `governance.citation_resolves` PASS, evaluated
   **154** subjects, 8 quoted meta-findings, 3 schematics (round 17 recorded
   125/6/3 — the checked population grew by 29 while staying clean; no
   measured-against pin is touched here). The full suite at HEAD is **exit 1**:
   `trigger.line_budget` FAIL, `601 lines exceed budget 600 (from box at line
   329)` — pre-existing and named in `SCORECARD.md` ("the inherited 601>600
   budget failure"), reproduced identically in the copy.
4. **Probe-methodology hazard (this lane, not the instrument).** My first
   quoted-token control silently lost its backticks in transport: the line
   reached disk as `M7 probe: "corpus/absent-m7-probe.md" quoted on its own
   line.` with codepoints `0x22 … 0x22` and **no `0x60`**, while the same
   heredoc's space-padded line kept both backticks (`has-backtick(0x60): True`).
   A backtick adjacent to a double quote is dropped somewhere between the tool
   call and the shell. Consequence: the first reading ("quoted control excluded
   the token but the counter stayed at 8") was an artifact — the file contained
   no span at all, so neither subject nor exclusion existed. Rebuilt with
   `chr(96)` (case B), the counter correctly reads 9. The instrument's
   `citation_subjects` is **not** under-counting. Any lane probing these
   predicates through a heredoc should build backticked tokens programmatically.
5. **The instrument's own self-test is red at HEAD and is not reproducible from
   the tracked tree** (defect D1 below): `--self-test` reports
   `2 failure(s) over 1504 assertions`, exit 1, in both the live tree and the
   copy, and returns to `0 failure(s)` the moment an untracked empty directory
   exists. This is a live red gate, contradicting the `0/1504` claims at
   `SCORECARD.md:33`, `SCORECARD.md:82` and `LOG.md:848` (defect D2).

## Defects named (each: path:line + evidence)

- **D1 — self-test fixture depends on an empty directory git cannot track.**
  `verifiers/fixtures/checklist/delegated-directory/map.json:15` carries
  `"disposition": "delegated:delegated-directory/probe-dir"`. The assertion
  (`verifiers/verify_skill_checklist.py:1612-1614`) expects the message
  `not an instrument`, which requires the delegated target to **exist** as a
  directory. It does not: `git ls-files verifiers/fixtures/checklist/delegated-directory/`
  returns only `SKILL.md` and `map.json`, and
  `git log --all -- verifiers/fixtures/checklist/delegated-directory/probe-dir`
  is empty — the directory was never tracked (git carries no empty
  directories). Live evidence, `python3 verifiers/verify_skill_checklist.py --self-test`
  → exit 1, `2 failure(s) over 1504 assertions`:
  `self-test FAIL: delegated-directory: names 'not an instrument': got "FAIL checklist.box_map_complete: evaluated 2 — map entry fixture.02 delegates to a target that does not exist: 'delegated-directory/probe-dir' …"`
  and the same for `FAIL not-an-instrument, no traceback`. Causality closed in
  the copy: with `probe-dir` present (`mkdir`), exit 0 and
  `0 failure(s) over 1504 assertions`; after `rmdir`, exit 1 and
  `2 failure(s) over 1504 assertions` again. Round 17's recorded
  `0/1504 over 71 fixture dirs` was therefore measured on a tree that carried
  the untracked directory; a clone, a `git clean -d`, or any checkout loses it
  and the gate turns red. No fix attempted (out of slice; round rules allow
  writing only this fragment).
- **D2 — governance claims now false at HEAD, and outside the predicate's
  reach.** `SCORECARD.md:33` ("`--self-test` is 0/1504 over 71 fixture dirs"),
  `SCORECARD.md:82` ("10 × PASS, `--self-test` 0/1504 over 71 fixture dirs") and
  `LOG.md:848` ("`--self-test` → **0 failure(s) over 1504 assertions**") are
  contradicted by the live run in D1. This is a *content* falsehood in a file
  the governance predicate reads: the predicate proves path existence only
  (`SCORECARD.md:33` itself names that limit: "path existence proves neither
  content, anchors, pins, symlink containment, nor historical truth"), so D2 is
  evidence that a green `governance.citation_resolves` does not imply the
  governance files are true — the M7 probe can therefore only certify the
  *predicate*, never the *claims*.
