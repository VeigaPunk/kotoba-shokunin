## Defects named

1. **`../AXES.md:68` — "every axis the lane owns" is undefined against advisory
   axes the lane is obliged to work.** Kotoba owns 2 axes but scores 7 and its
   lowest-axis rule steers rounds at advisory axes (`SCORECARD.md:3,12-15`,
   `:30-34`). Evidence: with the line scoped to owned axes, both sit ≥ 9; with
   it scoped to all scored axes, the binding minimum is 8.0. The two readings
   give different nudge verdicts — the fleet's precedents differ the same way
   (`../souji-shokunin/SCORECARD.md:44` whole-set vs
   `../kaidoku-shokunin/SCORECARD.md:628` owned-proxy). The draft above takes
   the owned-proxy reading and says so; the integrator should record the choice.
2. **`../AXES.md:69-70` — no effective-from semantics.** A declaration recorded
   in round 21 would, read literally, retroactively waive round 21's
   pre-registered lowest-axis claims F/A (`.ufo/round-21/claims.json:29-48`).
   The draft states the convention (binds from round 22) explicitly because the
   protocol does not.
3. **`../AXES.md:68-70` — condition (2) is vacuous for a lane that has never
   entered a capability row.** Evidence: `SCORECARD.md:121` and
   `LOG.md:1201-1206` (table created 2026-10-16, no row since). Any N ≥ 1 is
   satisfied by history alone, so N is unobservable as a trigger for this lane;
   the line carries the entire decision. Compare `../kaidoku-shokunin/SCORECARD.md:631`,
   where the table had rows inside the window and condition (2) was non-vacuous.
4. **`../AXES.md:68-69` — the window's round unit is undefined.** Blocked
   attempts are explicitly "attempt namespace, not completed-round count"
   (`SCORECARD.md:88-89`) with "no verified-round credit" (`:115`), yet the
   nudge speaks of "the lane's stagnation window" in rounds. Evidence: round 20
   is a dispatched attempt with zero verified-round credit and zero movement.
   The draft counts dispatched lane-rounds; the integrator should pin this or
   blocked rounds will silently not age the window.
5. **`PROVINCE.md:1-6` — no frontier inventory, so the nudge's frontier route
   has no target in this lane.** `AXES.md:71-73` presumes frontier ground exists
   to move into core; kotoba's province file is domain/owns/refuses only, and no
   frontier candidate is named anywhere in-repo (only `SCORECARD.md:95`'s "no
   frontier admitted"). Effect: a nudge-firing round can only be a capability
   round as things stand; if the integrator wants the frontier route, the
   inventory must be created first.
6. **`SCORECARD.md:31,32,34` — malformed axes-table rows in the very file the
   declaration lands in.** Pipe counts per line: header/separator/depth/
   consistency/coverage = 6 each; **operability `:31` = 4, freshness `:32` = 3,
   adjacency `:34` = 4** (calibration `:33` = 6). The `Owned?`/`Last change`
   cells are missing for three rows, so the owned/advisory distinction the
   saturation line depends on is only machine-readable for four of seven rows.
   Evidence: `awk 'NR>=26 && NR<=34 {gsub(/\|/,"\|"); ...}'` (command 7).
7. **Self-citation drift on paste (calibration note, not a file defect).** The
   draft cites `SCORECARD.md:NN` line numbers; once pasted into that file, every
   one of those numbers shifts by the pasted block's length and the placeholder
   lines `:125-127` disappear. The integrator should re-anchor to section names

   class in its history (`SCORECARD.md:76`, the round-12 census note).
