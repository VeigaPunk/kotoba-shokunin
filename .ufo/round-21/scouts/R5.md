## Defects named (each: path:line + evidence)

**R5-D1 — `--self-test` is red at HEAD: the `delegated-directory` fixture lost an
untracked empty directory.**
`verifiers/fixtures/checklist/delegated-directory/map.json:15` carries
`"disposition": "delegated:delegated-directory/probe-dir"`, but
`verifiers/fixtures/checklist/delegated-directory/probe-dir` does not exist
(command 8) and never was tracked (commands 9, 11: only `SKILL.md` + `map.json`
tracked; `git log --all -- '*probe-dir*'` empty — git cannot track empty
directories, so the round-16 fixture lived only in a working tree). Evidence:
command 3, `rc=1`, `2 failure(s) over 1504 assertions`, both from case
`delegated-directory` (self-test row `verifiers/verify_skill_checklist.py:1469`,
targeted extra at `:1612-1614`); the observed detail is
`map entry fixture.02 delegates to a target that does not exist:
'delegated-directory/probe-dir'` where the test demands `not an instrument`.
Consequences: (a) the round-17 record "0 failure(s) over 1504 assertions" is not
reproducible at HEAD; (b) the `is_instrument` non-file guard
(`verifiers/verify_skill_checklist.py:704`) now has **zero** fixture coverage —
the check exits on the `exists()` branch one line earlier; (c) a fresh clone
reproduces it (command 14). Repair shape (not executed — outside this lane's
write scope): make the target a tracked non-file path, or create the directory
inside the self-test with `tempfile`.

**R5-D2 — the live gate is red at HEAD: SKILL.md exceeded its own line budget.**
Command 2, `rc=1`: `FAIL trigger.line_budget: evaluated 601 — 601 lines exceed
budget 600 (from box at line 329)`. `SKILL.md:329` binds `File ≤ 600 lines`
(threshold taken from the box text); `wc -l SKILL.md` = 601 (command 12).
Introduced after r17's recorded 599 by round-18 commit `02302c5` (`git log --
SKILL.md`, command 5-adjacent run). This falsifies any round-21 "every live gate
green at HEAD" reading for this instrument.

**R5-D3 — `--self-test` is not hermetic outside a git checkout.**
Command 13: a `.git`-less extraction of `verifiers/` yields `rc=1`,
`110 failure(s) over 1504 assertions` over 70 distinct cases (e.g.
`command-redirect-target` 5, `command-heredoc-tilde` 4, `citation-ok` 4). Cause:
`find_repo_root` (`verifiers/verify_skill_checklist.py:386-392`) falls back to
the fixture's own directory when no `.git` ancestor exists, and several fixtures
cite live repo files — e.g. `verifiers/fixtures/checklist/citation-ok/SKILL.md`
cites `corpus/knowledge/anatomy-and-compression.md` and
`verifiers/verify_skill_checklist.py`. The docstring's claim that `--self-test`
"exercises fixtures only" (line 249) holds only inside a git checkout. Lower
severity than D1 (a checkout is the normal deployment), but it means the
self-test cannot be used as a post-deploy smoke check and any CI that copies the
tree without `.git` sees 110 phantom failures.
