## Defects named (each: path:line + evidence)

- **D1 — `../kasegi-shokunin/corpus/instruments/anchorcheck.py:283`**: `sys.exit(main(sys.argv[1:]))`
  while `main()` has no `return` → the gate is exit-0 **always**. Live: a run
  reporting `3 bad` cites returned rc=0 (Command 6). Pre-existing — the round-16
  bytes behave identically — so it is a standing defect, not a regression. Any
  consumer that reads the exit code as the verdict reads PASS on a failing file.
- **D2 — `../kasegi-shokunin/corpus/instruments/anchorcheck.py:216` + `:219`**: a
  *slashed* lane-relative cite that misses the lane is re-based under `MIRROR`
  (`path = os.path.join(MIRROR, rel); kind = 'MIRROR'`) and, because the mirror is
  absent on this host, classifies `BASE-ABSENT` instead of `MISSING-FILE`. The
  summary's `bad` count therefore under-reports genuinely dead lane paths. Live
  evidence (Command 8): `corpus/absent-a6.md:1` → `BASE-ABSENT (base tree absent:
  /home/vgpnk/Projects/the-bounty-hunter/corpus/absent-a6.md)` although the lane
  root was correct and the file is simply absent. The bare-name half of this is
  documented in the module docstring §(e); the slashed-relative half is not, and
  it is the half that moves the `bad` headline.
- **D3 — `SCORECARD.md:34` vs `corpus/knowledge/sibling-citation-routing-round16.json`**:
  the recorded per-sibling parenthetical ("kasegi 1", total 10) contradicts the
  artifact that round-16 landed (5 kasegi findings, 14 findings total), and the
  artifact is the side that reproduces live at HEAD (Findings 6). Round 21's
  A-claim "delta vs round-16 counts" must quote the json, not the SCORECARD prose,
  or it will report a spurious +4.
- **D4 — `verifiers/verify_skill_checklist.py:1215` vs `:1203-1207`**: the trigger
  variant of the R3 predicate calls `citation_subjects(lines)` with no exclusions,
  so ellipsis schematics count as dead, while the governance variant excludes and
  counts them. Live effect: kagi's entire count (2 = `corpus/…`, `.ufo/…`),
  kasegi's `L304 .ufo/…` and kumitate's `L671 .ufo/…` are schematics — 4 of the 14
  live "dead" tokens are not dead promises. One instrument, two rules for one
  class.
- **D5 (open dialect gap, re-measured — not a new defect) —
  `../kumitate-shokunin/scripts/surface-probe.mjs:858`**: execution-only checklist
  model; a dead path argument is invisible whenever the command's exit code and the
  expected substring both hold. Round 16 named this; it is unchanged at round-21
  HEAD (Findings 1, 4) and the consolidation call is still kumitate's/protocol's.
