## Findings

1. **Cwd-independence CONFIRMED for the live gate.** Runs 1/2/3 agree byte-for-byte,
   text and `--json`, and the no-arg foreign run (5) agrees too. Resolution bases are
   absolute (`repo = Path(args.repo).resolve()`, `:1752`; `DEFAULT_REPO` from
   `__file__`, `:269`; vocabulary/fixtures from `VERIFIERS_DIR`, `:270-271`).
2. **A cwd-local file cannot launder a dead head.** Copy probe: appended
   `f7decoybin --version` in a ```bash fence to `/tmp/f7/copy/SKILL.md:604`.
   (A) no decoy → `FAIL … line 604: 'f7decoybin' … does not resolve`, exit 1.
   (B) executable `/tmp/f7/f7decoybin` present in the cwd, PATH unchanged → **same
   FAIL**, exit 1. Cwd does not enter `safe_resolve` (`:674-693`).
3. **But the verdict is PATH-coupled, and a relative PATH entry re-introduces cwd.**
   (C) same tree, same cwd, `PATH=".:$PATH"` → `PASS trigger.command_binary_resolves:
   evaluated 20 … 20 command subject(s) resolve`, exit 0. `safe_resolve` calls
   `shutil.which` (`:685`) and Python consults a relative PATH entry against the cwd.
   Likewise run 11 (`env -i PATH=`), on the untouched live tree from `/tmp`:
   `FAIL trigger.command_binary_resolves: evaluated 19 — 15 segments; line 105:
   'md5sum' … does not resolve; … (+11 more)` — the same tree flips PASS→FAIL with an
   empty PATH. "Same verdicts from a foreign cwd" therefore holds only for a fixed
   PATH; this is a named limit, not a defect.
4. **A relative `--repo` is cwd-relative by design** (run 10): `--repo kotoba-shokunin`
   from `/tmp` resolves to `/tmp/kotoba-shokunin` and the run FAILs 4 checks naming
   that path (`line 79: 'corpus/knowledge/instruction-surface-census-round13.md' does
   not resolve from /tmp/kotoba-shokunin`). Cwd-independent invocation requires an
   absolute `--repo` or none.
5. **The literal slice argv (run 4) cannot work from a foreign cwd** — a shell/Python
   path-resolution fact, not a gate defect. The gate must be invoked by absolute
   script path (or from the repo).
6. **`--self-test` is RED at HEAD: 2 failures / 1504 assertions** (runs 8, 9), and a
   **fresh clone reproduces them identically** (run 13) — the defect is in committed
