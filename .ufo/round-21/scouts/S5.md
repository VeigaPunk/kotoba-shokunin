`surfaceSha256` names `LOG.md = 3b0c39ff3ba40f0b5f8f6f480604b251bfdf9279d21bd9ce37d2473296e5788d`;

`"disposition": "delegated:delegated-directory/probe-dir"`. `git ls-tree -r HEAD -- verifiers/fixtures/checklist/delegated-directory`

"not an instrument" branch at `verifiers/verify_skill_checklist.py:702`, so the assertions at
`verifiers/verify_skill_checklist.py:1458`, `:1470` and `:1614` cannot pass. Evidence: command 10.

**D3 — `SCORECARD.md:33`, `SCORECARD.md:82`, `LOG.md:848` — recorded `--self-test` green is not
reproducible.**
All three record `--self-test` → `0 failure(s) over 1504 assertions` (SCORECARD.md:33 and :82 for
round 17; LOG.md:848 the round-17 log). Measured at HEAD, in a fresh clone of HEAD, and in a faithful
round-17 tree: **exit 1, `2 failure(s) over 1504 assertions`**. The recorded zero is reachable only
in a working tree carrying the untracked empty directory of D2. Evidence: commands 9, 10, 11.

**D4 (minor) — `verifiers/verify_skill_checklist.py:387`–`:390` — `--self-test` is documented
"fixtures only" but depends on a `.git` ancestor.**
`--help` states `--self-test` "assert all checks and exit codes on fixtures only (separate mode; rc is
not comparable to a live run)", and the default `--repo` is "the nearest ancestor of `--skill`
carrying `.git`, else its dir" (`:1707`–`:1708`). Running the same committed tree from a
`git archive` extraction (no `.git`) yields **110 failure(s) over 1504 assertions**; adding `.git`
back yields `2 failure(s) over 1504`. So self-test output is environment-sensitive, and only the
`.git`-bearing numbers are comparable to the record. Evidence: command 10 and the archive/cp-`a`
contrast.
