# Scout M3

## Task
Red probe: corpus dead pointer in a /tmp clone. HEAD b761cd6; repo read-only, mutation on /tmp only.

## Commands
- `cp -a` -> `Disk quota exceeded` (/tmp had 4.5G free — quota, not size); `git clone --local` ->
  `Invalid cross-device link`. Used `cp -al` + `git clone --no-hardlinks file://<repo>`, the shape
  `fault_injection_corpus.sh:76-78` uses.
- `python3 verifiers/verify_corpus_integrity.py --repo .` / `--self-test` in a fresh `file://` clone;
  `verifiers/fault_injection_corpus.sh --self-test` on the live tree; `unshare -rm bwrap --dev-bind / /
  --bind <empty> /home/vgpnk/Projects/shokunin ...` to mask the host fleet root for the clone.

## Findings
- Baseline: fresh clone `report_dead=0/36`, `9/9 checks pass`, exit 0; tracked=53; shapes
  `relative=1 absolute=34 tilde=1`; self-test `0 failure(s) over 88 assertions`.
- **Clone-local dead pointer flips the gate.** A dead relative pointer appended to
  `corpus/README.md` -> `report_dead=1`, DRIFT `report_total`+`report_dead`, exit 1; likewise a
  dead host-absolute pointer, and deleting the one relative pointer's clone-local target
  (`README.md:57` -> `../.ufo/reports/round-23/kotoba.md`).
- **The clone's green is a host measurement.** Deleting the clone's OWN reports
  (`.ufo/reports/round-{7,11}/kotoba.md`) leaves it green (`report_dead=0/36`, exit 0); masking the
  host fleet root turns the same clone red (`report_dead=35/36`, DRIFT, exit 1). Only 1 of 36
  checked pointers resolves inside the clone: 32 into the fleet root
  `/home/vgpnk/Projects/shokunin/.ufo/...` (shared across repos), 3 host-absolute into this repo.
  Mechanism: `verify_corpus_integrity.py:491` `resolve_pointer(_repo / base, token)` — rooted tokens
  (`/`, `~`) bypass `_repo` (`:208-214`). Not new: `independent-verification-round12.md:110-114`
  records it, `corpus-integrity-round11.md:248-250` names the portability gap; no gate asserts it.
- INDEX control: a dead **relative** File-column token fires `missing_paths=1`+`stale_patterns=1`;
  the same token **absolute** fires neither (`is_corpus_internal`, `:191`).
- Documented blind spot re-confirmed: a pointer moved out of the round-N grammar -> `report_total`
  36->35, DRIFT by default, `9/9` under `--no-baseline`.
- Live tree unmutated; `git status --porcelain` shows only untracked `.ufo/round-30/`.

## Defects
1. (high) The clone probe is not hermetic — a fresh clone's corpus green is decided by the host fleet
   root, so `fault_injection_corpus.sh`'s per-fault worlds inherit the host `.ufo` and no gate asserts
   it. The P5-vs-P6 pair discriminates.
2. (medium) `corpus.index.missing_paths` is vacuous for any non-corpus-relative File-column token.
3. (low) `corpus-baseline.json`'s `measured_against.head` (`d85982d`) predates the last three
   refreshes; the notes carry the real record.

## Limits
- Copies came from a hardlinked/`file://` clone, not `cp -a` (quota); byte-identical for tracked files,
  and the live `.ufo/round-30/` is absent from clones. Masking used `bwrap`; `unshare -rm` alone does
  not hide the host path. Single-run observations.
