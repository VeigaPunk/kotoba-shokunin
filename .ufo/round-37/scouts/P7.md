   fail-loud via map custody. V6's container-aware spec implementation is the
   independent oracle for a deeper red-team.

   -> the F8 info-string command leak, and the F7 convention mismatch with the
   pinned matrix. Recipe (2 hunks + pins): add the opener and closer lines to
   `inside` in `fenced_regions`, then add the delimiter line numbers to the 12
   `FENCE_SHAPES` *content* pins and re-record the floor (1584 -> 1584+12ish),
   plus re-run P8's probe (expect 12/12 OK) and the 76-file sweep (expect 0
   diffs; no live fence line carries a vocabulary span). Recommendation:
   adopt delimiter-inclusive — it is cmark's node span, it closes the leak, and
   it makes the pinned independent matrix pass exactly.
4. **[open, adjacent instruments, MED-LOW] F9** — same spec-closer class in
   `verify_corpus_integrity.py:154/304` and `verify_corpus_independent.py:106/216`.
