## DEFECTS

Mine: **D1 (LOW)** `audit_blindness.py` thresholds (run≥6, jaccard≥0.05, ≥3 pinned values)
are heuristic; they caught the planted fixtures but a determined paraphrase could pass —
the tool is a filter, not a proof. **D2 (LOW)** the tool's `MISSING` arm exits 2 for the
whole run, so a not-yet-written report masks nothing but does force one re-run.
**D3 (LOW)** my first run of a control silently failed on `parents[4]` instead of the repo
root (fixed to `parents[5]`); the driver's own fail-closed behaviour (exit 2, "independent
instrument failed with no stdout") is what surfaced it. **D3b (LOW, fixed)** `audit_blindness.py`
raised `IsADirectoryError` on a directory target (the builder's fixtures); it now walks
directory targets, and the fixture scan is CLEAN.

Others: **D4 (MEDIUM, C1)** instrument ignores `HOME` isolation — its substrate defaults are
host-absolute, so a mutant tree is only reachable through its flags; the claim's "pinned
mutant tree" should say which mechanism it means, otherwise a reviewer cannot re-run it
hermetically. **D5 (MEDIUM, C1)** the declared counting command
`python3 verifiers/verify_harness_independent.py` prints `24 derived / 4 unlanded` and exits 0
while the agreement verdict lives in `compare_harness_independent.py` (exit 1); the claim's
"N/N check agreement" is therefore not measured by its own counting command. **D6 (MEDIUM,
C1)** agreement is reported under three predicates (22/24 internal, 23/28 protocol, 17/28
strict) — the report must pin one and publish the other two beside it. **D7 (HIGH,
verification value, C1)** the headline count is satisfiable by a no-derivation echo
(28/28, exit 0) and 15/28 is available to a null instrument: the evidence pack needs the
canary + blindness audit (or equivalent) or the number certifies nothing. **D8 (MEDIUM,
C1)** 4 of 28 checks are `UNLANDED` (all `omp.catalogue.*`), i.e. at most 24/28 is
re-derivable today. **D9 (LOW, C1)** `provisional (unlanded-based agreement)` appears in
the driver output (1 in the live run) without a definition in the claim or the report.
**D10 (MEDIUM, lane)** `oc.log.skills_tag_hits` and `oc.dup.roots_both_sided` remain
substantive disagreements after my independent count corroborates `13` (and, in the strict
column, 11 rows disagree) — these need a named third-seat adjudication, not the driver's
own predicate.
