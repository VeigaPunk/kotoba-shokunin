## Deliverable

`verifiers/compare_harness_independent.py` (new, untracked — parent commits). It embeds no
expected value, no check-id list and no baseline: it runs both instruments and joins their
outputs. Consumes the IND instrument's `--json` in any of four shapes (records under
`results`/`rows`/`checks`, a nested dotted `checks`/`expected` map, or a flat dotted map),
which is why it already works against the landed IND payload unchanged.

Two agreement columns, both always computed:
- **strict** — type-tagged value equality (`1 != True`, `7 != 7.0`, list order significant);
- **protocol** — A1's frozen mode predicate (protocol §2): `equal` → equality, `zero` → both
  readings empty, `positive` → numeric direction. Unknown mode → named, exit 1 (never smoothed).
Headline = protocol; strict is reported alongside; rows where they differ are named as
**adjudicated** (exit 0 only if the predicate holds). `--strict-headline` makes strict
decisive (red-team mode). Rows whose *agreement* rests on an IND reading the instrument itself
marks non-`DERIVED` are named **provisional** and fail the run — an UNLANDED `None` cannot
launder into agreement through the `zero` emptiness predicate.
