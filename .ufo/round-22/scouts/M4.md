## Findings

**F1 — control is fully green on the real dump.** Run #4: all 7 checks PASS, exit 0;
the loader census resolves 8/8 pairs and the opencode rules 5/5 classes from 6/6 rules
against the live binary bytes.

**F2 — the vacuity guard fires on the REAL substrate shape.** Run #7 (broad) and #10
(shape-only) both exit 1 with the exact message
`vacuity: 0 loader class(es) extracted from the omp dump while the baseline declares 8
loader-group class(es) for it — a moved or renamed substrate must FAIL, never pass
silently` (`verifiers/verify_surfaces.py:551-561`). The strip targets exactly the
registration shapes the live dump uses — all 11 of them, produced by the three live
callees Co(4)/Dl(5)/Hj(2) — so this replays the round-21 defect class
("2026-10-16 omp rebuild registered through renamed callees") against real bytes. The
existing self-test only exercises the guard with an EMPTY dump fixture
(`verifiers/verify_surfaces.py:793-798`, `strings-empty.txt`); run #7/#10 supply the
distinct real-shape witness.

**F3 — the guard's trigger condition is boolean zero-extraction; coverage below that is
literal_present's, and it holds.** Run #11 (only `Dl` renamed → 6 pairs left):
`no_uncovered_class` PASSes on the shrunken-but-declared set, while `literal_present`
FAILs exactly the 2 classes whose call shape vanished
(`omp:opencode/AGENTS.md`, `omp:windsurf/memories/global_rules.md`). This matches the
documented division of labour (`verifiers/verify_surfaces.py:522-529` vs `:540-547`) —
partial substrate loss is caught (exit 1 overall), so no check-level gap was found at
any strip depth tested.

**F4 — callee→class map on the live dump (minification-volatility context).**
`github/copilot-instructions.md` extractable only via `Co`; `opencode/AGENTS.md` and
`windsurf/memories/global_rules.md` only via `Dl`; `agents-md/AGENTS.md` and
`claude-md/CLAUDE.md` only via `Hj` + var-resolution of the quoted group argument.
Relevant to the per-harness allowlist note (`verifiers/verify_surfaces.py:136-162`): a
renamed callee whose pair has no other producer takes the vacuity/literal_present route
(observed), and a renamed var takes the literal_present route via
`<unresolved-var:NAME>` (code path at `:325-330`, not exercised this round).

**F5 — fault-injection hygiene.** All mutation is on `/tmp` copies; the live repo, the
fleet root, and siblings were read-only throughout; the strip is a text-level dump
mutation whose effect was re-measured with the verifier's own `extract_classes`
(0 pairs after strip, 8 before), so the red is attributable to the callee shapes and
not to dump damage — literals (`GEMINI.md`, `AGENTS.md`, …) are still present in the
stripped file (run #6).
