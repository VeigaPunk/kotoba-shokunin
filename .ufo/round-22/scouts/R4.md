**F5 — The ad-hoc shell counting command for this class silently over-counts by 4.**
`git grep -h -o -E 'commit[ \t]+`[^`]*`' -- 'corpus/*.md' | wc -l` → **33**, but the
true candidate population is **29** (27 hex + 2 quoted). In a POSIX bracket expression
`\t` is not TAB but backslash+T, and combined with the space it matches the
backslash-escaped literal forms `` commit \`round-[0-9]+\` `` at
`corpus/knowledge/claim-census-round12.md:32,82,85` and `corpus/lessons/round-10.md:90`.
A tab-class pattern (`$'...[\t ]...'`) yields 29. The shipped verifier is correct here
(Python `re` reads `\t` in its pattern as TAB), so this is a trap for hand-written
checks — exactly the "command that cannot express its own class" defect family of the
round-11 doc's own §Trigger.
