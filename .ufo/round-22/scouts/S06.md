   move the counts. Pre-move and post-move both print `15/9/9/8` (M4/M5), and
   `grep -c '^- \[ \]'` stays `41` (M3) — the box map still evaluates 41 (A1).
2. **The carried red clears.** 601 → 559 lines; the gate goes from 10/11 rc 1 to
   **11/11 rc 0** with all six other instruments green (A2–A6). The moved block
   is byte-identical in its home and the home edit is append-only (M6/M7).
3. **Two box-1 evidence sub-claims are already stale, independent of this move**
   (see Defects 1–2). The move neither causes nor cures them, but the B landing
   should repair line 15 while it is open — box 1 is the box that certifies
   exactly this kind of move.
4. **The stub must keep the heading, and nothing enforces that.** Line 248's
   `(§ Router model)` is the only intra-file anchor to the moved section; V1
   shows the checklist gate stays fully green with the heading deleted, so
   heading retention is a hand discipline, not a gate.
5. **Home choice decides the corpus-side cost.** Appending into the already
   indexed `harness-router-models-round9.md` + a README Basis-cell note keeps
   both corpus instruments green with **zero baseline churn** (A2/A3). A new

   a `corpus-baseline.json` `tracked_files` refresh 52→53 (V3). The round-15 idiom's
   "+ README index row" therefore means *update the existing row* here.

   less after the move: citations 42→37, command segments 15→12, placeholder
