## Findings

- (a) GREEN. `strings-omp-newcallees.txt` is tracked (blob `f813a478…`, 464 bytes,
  committed `2ca8d01`), unchanged vs HEAD, and `OMP_CALL_RE` (via the script's own
  `extract_classes`) extracts exactly the two declared loader-group omp classes; the
  script's `literal_present` and `no_uncovered_class` both PASS on it. Live surfaces
  self-test 0/75 exit 0, and the archive-export surfaces self-test is also 0/75 exit 0.
- (b) `probe-dir/.gitkeep` is tracked (blob `1cfdd30e…`, 231 bytes, `2ca8d01`) and IS
  present in a fresh `git archive` export; the `delegated-directory` fixture case reaches
  its expected "not an instrument" branch in the archive layout, so the round-21 fixture
  repair survives archiving.
- (b) RED, one root cause. A fresh `git archive` export FAILS the checklist self-test:
  108 failures / 1504 assertions, exit 1 — while the live tree and a fresh clone are
  0/1504 exit 0. Mechanism: `find_repo_root` (`verify_skill_checklist.py:386-392`) takes
  the nearest ancestor carrying a `.git` marker and, absent one, falls back to the file's
  own directory. The self-test argv (`:1341-1348`) passes `--skill <fixture>/SKILL.md`
  and no `--repo`, so in a `.git`-less tree the repo root becomes the fixture directory.
  `governance_enabled` (`:1756`) then compares skill path to `repo/SKILL.md` — which now
  MATCHES — activating the governance read (`:1838` N/A branch is skipped) against
  `LOG.md`/`SCORECARD.md` inside the fixture dir → unreadable → FAIL; the same shifted
  base breaks repo-rooted citation/command resolution (`corpus/…` operands) and flips
  ~26 exit-0 cases. Injecting a single empty `.git` dir into the export restores 0/1504
  exit 0 — causally closed.
- Claim-scope consequence: round-21's recorded "self-test green from a fresh clone" is
  TRUE (clone has `.git`, verified at `:14`), but the archive/tarball/artifact layout was
  never measured and is red. Any future evidence recorded from a non-git export of this
  tree will read 108 failures unless `--repo` is passed or a layout note is added.
