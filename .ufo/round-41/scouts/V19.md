## Container residual

For the list fixture cmark emits a code block at source position `10:3-12:8`; line 14, the B row, is a paragraph outside that block. In CommonMark container context the list's two-column prefix is removed before interpreting fence indentation, so the closer has two relative spaces and is legal. The frozen drivers close it; the landed `^ {0,3}` raw-line regex does not. The landed scanners therefore keep the region open through EOF and suppress the live line-14 row. Both CLI gates exit 1 with `unindexed=1` instead of accepting the cmark-visible coverage row. This is conservative (false-positive drift), not a silent false pass, but it is a real regression for fenced coverage inside a list container.
