## Mechanism and disposition

`LIVE_VALUE_KEYS = ("observed",)` is appropriate for value-channel comparison: the live record's `expected` is not another observation. `_channel_maps()` recognizes `results`/`rows`/`checks` (`compare_harness_independent.py:246-258`) and `_reconcile()` compares their values, statuses and membership (`:361-423`). H1 already reported the live `rows` shadow (R40 `H1.md`, q1), and P2 noted the foreign `expected` field; these are re-measured here, not claimed as first discoveries. The mode/verdict ordering arms are additional live-metadata probes.

The reconciliation does not include every field later consumed by `parse_live`. `_channel_maps()` only rejects a duplicate id when its value differs (`:339-345`); `parse_live()` then assigns `observed`, `verdict`, and `mode` into dictionaries (`:483-494`), so duplicate equal-value records can overwrite metadata. `compare()` consumes the returned live `modes` (`:463-466`); for `positive`, `predicate_agree()` accepts when independent ≥ live (`:184-194`). `decide_exit()` trusts the returned verdict map (`:876-885`). The duplicate verdict arm therefore hides an earlier `DRIFT`, and the mode arm changes the primary classification. These are open live-payload metadata channels on both the frozen and current drivers, not regressions introduced by the r40 value-channel fix. Whether to trust the live instrument's mode/verdict fields is a protocol boundary; this report makes no claim that the normal live producer emits those hostile mutations.

The foreign `expected` field is deliberately absent from `LIVE_VALUE_KEYS`, but `build_meta()` separately reads it for `secondary_agree` (`:1952-1959`). That count is thus payload-controlled. In the alignment arm, the numerator reaches 28 while the primary join scope remains 24; the secondary metric is not a primary exit gate, but its displayed ratio can be misleading.

The producer's top-level `observed` object is a nested raw summary (`verify_harness_claims.py:648-660`), not a `CHANNEL_KEYS` record channel. It is ignored by `parse_live`; the shadow test changed it without changing the join. This is a contradictory display surface, not a demonstrated join-laundering path.
