## Why / residual

`load_scope_file()` reads `Path(path)` at process cwd (`verifiers/compare_harness_independent.py:613-624`, called at `:1925`). `render_receipt()` resolves that same relative string against `--cwd` (`:1196-1202`), while the receipt records `driver_cwd` but not process cwd. Thus the same path string can name two files. The planted end-to-end probe used a relative `verifiers/harness-independent-scope.json` from `.ufo/round-41/drafts/d02/planted`, while `--cwd` remained the lane root; a valid extra `omp.offered.skills` scope row then passed at 23/23. This reproduces R1’s F-3′ on frozen and live bytes.

The receipt’s `probe_kind` is selected from the first payload probe (`:1938-1942`), not from the loaded contract. `check_scope_probes()` validates probes only for declared scoped rows (`:777-819`); an unassociated extra probe can therefore furnish the receipt field without affecting the 24/24 join.
