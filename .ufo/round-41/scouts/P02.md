## Finding and proposed change

At frozen `b1be35f9522f21c0c5b39879358a011806ab9200`, `probe_contract` pins the probe kind but has no target. `check_scope_probes` passes each payload's `probe.target` directly to `recompute_probe`, so a payload can redirect the census to its own carrier.

The patch adds `probe_contract.target: "$HOME/.omp/agent/sessions"` to `verifiers/harness-independent-scope.json`. The comparator resolves that committed token (`$HOME` expands via `Path.home()`), checks that the payload target resolves to the same path, then recomputes on the committed target rather than the payload value. A mismatch is a named `false blocker` (exit 2). The added self-test replaces the old empty-target-only redirection arm with a valid two-file alternate carrier, retaining the empty committed-carrier check; self-test assertion count stays at 118, so no floor bump is proposed.
