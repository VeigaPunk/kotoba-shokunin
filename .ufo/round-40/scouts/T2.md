## 1. What I built

`.ufo/round-40/drafts/t2/` (1.8 MB at write time; counting inputs only — frozen predicate blobs, the
probes that produce the numbers, no repo copies, no `.git` symlinks):

| artifact | role |
|---|---|
| `fence_regression.py` | the harness: `capture` / `diff` / `oracle` / `cmark` / `regression` / `selftest` |
| `mkvariants.py` | builds the frozen predicate revisions (count-checked anchors + `py_compile`) |
| `differential.py` | 80-shape differential vs cmark over five predicate forms |
| `readme_e2e.py` | end-to-end: a quoted coverage row in `corpus/README.md`, per revision |
| `stale_residual.py` | end-to-end: a *stale* coverage row below the opener-side shape |
| `indent_fork.py`, `nonvacuous.py`, `opener_residual.py` | the probes behind §4/§5/§6 |
| `frozen/` | the predicate revisions (§2), each sha256-stamped |
| `out/` | every capture, diff, matrix and receipt quoted below, plus `RECEIPT.txt` |

**Design decision that matters.** A harness that only diffs before-vs-after cannot
distinguish "changed exactly where intended" from "changed somewhere else" — both show a
delta. So every capture is graded against this harness's **own re-derivation** of the
predicate (`oracle_fence_set`, three revisions) *and* against **cmark 0.31.2** as the
external authority. A doc is `INTENDED` only when its before-set equals the no-clause
oracle and its after-set equals the declared-clause oracle; a doc carrying an
intended-shape line whose set did **not** move is `MISSED` (the clause claims coverage it
did not deliver), and anything else is `UNINTENDED`. `diff` exits non-zero on `MISSED`
or `UNINTENDED`.

## 8. My own defects (disclosed, not smoothed)

1. **My first `differential.py` classification was wrong and would have produced a false
   claim.** I classified a shape by "extra non-empty → over-fence(fail-safe)", which hid
   every `cmark_extra` — i.e. it reported 24 divergences as *fail-safe noise* when each
   also had a **silent** part. Caught by re-reading the output against the raw sets;
   rewritten to classify `over_only` / `under` / `both` separately. The pre-fix run is in
   the transcript; the file now reports `both=24`.
2. **Four hand-derived oracle expectations of mine were wrong** in `fence_regression.py`'s
   selftest (I forgot that a shape line inside a region is itself part of the set, and
   that the `both` variant drops the line). The code was right each time; I fixed the
   table from traced output. Kept as history in the selftest's comment.
3. **A real design gap I introduced and then closed:** a doc carrying an intended-shape
   line whose set does *not* move initially read `UNCHANGED`, so a clause that silently
   failed to deliver would have passed. Now `MISSED`, and `diff` exits non-zero on it.
   The no-op-diff selftest then had to be split: a no-op on a clause-implementing variant
   is green, a no-op on `at-head` must name `MISSED`.
4. **My first two end-to-end worlds were wrong** and produced meaningless all-`DIFFERS`
   matrices: the coverage row was outside the `## Coverage map` section (the harvest is
   section-scoped) and used `corpus/`-prefixed tokens where the live README uses
   corpus-relative ones; and I had the cited doc missing, which makes the failure a
   *missing-path* error rather than the silent false-PASS I was trying to show. Rebuilt
   to match the live README's shape; the corrected matrix is §5.
5. **An anchored variant I built had an ordering bug** (added the line to `out` before
   the opener admission test), so it read 12/80 against its own oracle. Caught by the
   consistency check, fixed, re-verified 0/80.
6. **Two of my own scripts crashed on a formatting bug** (`%` on a 2-tuple) and one had
   an anchor that did not match (I searched `elif run[0]…` without the leading `elif`);
   both fixed before any number was quoted.
7. `nonvacuous.py`'s first cmark-truth printout listed block *starts* only; the
   ghost-row positions it printed were correct but I read them as spans for a moment.
   The `readme_e2e.py` output is the version that carries spans.
