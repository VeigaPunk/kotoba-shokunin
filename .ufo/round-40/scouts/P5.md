### 3.1 The mechanism, stated precisely

* **F-2** — `IND_VALUE_KEYS = ("expected", "expected_value", "re_derived", "value",
  "observed")` and `key = next((k for k in IND_VALUE_KEYS if k in record), None)`.
  A record `{"check": …, "expected": 7, "re_derived": "NOT DERIVED", "status":
  "DERIVED", "value": "NOT DERIVED"}` is scored on `expected`. Substrate check: the
  live IND emits **0** records carrying `expected`/`expected_value`, and the literal
  `"expected"` appears nowhere in `verify_harness_independent.py` — the key is not
  part of the independent instrument's vocabulary at all.
* **F-3** — `_record_list` returns the **first** of `results`/`rows`/`checks`; the
  other two are never read. The live IND publishes all three (28 records each, and
  their values are exactly consistent — 0 mismatches over 28 records including the 4
  scoped rows), so the reconciliation is safe to require on the live tree.

## 4. P5's own finding — the SHAPE channel (extension, not graded)

The driver's docstring documents a flat `{"<dotted.check.id>": value}` map and a
nested `checks`/`expected` map as accepted independent shapes. **Those shapes carry no
per-record `status`, no derived field and no evidence**, so a payload in them is a
pure copy — every value is whatever the harness printed. Measured on frozen
`1d027f2` (`out/shapespace/*.out`):

| shape | exit | headline |
|---|---|---|
| `flat-map-28` (all 28 harvested) | **0** | **28/28**, `0 scoped out` |
| `nested-expected-map` | **0** | **28/28** |
| `rec-value-only` (bare `value`) | **0** | 24/24 |
| `rec-expected-value-only` (bare `expected_value`) | **0** | 24/24 |
| `rec-observed-only` | 2 | closed — but via the **scope-status** channel, not a derivation check |
| `flat-map-24` (joined rows only) | 2 | closed by a count rule only |

Two things this adds to C1's own claim:

1. **`expected` is one entry in a priority list; the shape is a second door.**
   Dropping `expected`/`expected_value` leaves `flat-map-28`, `nested-expected-map`,
   `rec-value-only` and `rec-expected-value-only` all green (measured: §5).
2. **`flat-map-28` inflates the denominator.** The 4 scoped-out rows reappear as
   agreement, so the headline reads `28/28` where the honest IND reads `24/24` with 4
   scoped out — the same scope-narrowing invariant r39 established, defeated by shape.

`shape-flat-map-divergent` (one value changed) exits 1, which proves the shape *is*
joined — it is unauthenticated, not ignored.
