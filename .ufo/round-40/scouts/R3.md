   selects `re_derived` first, manufacturing a channel split rather than a
   genuine disagreement — it read exit 2 where exit 1 was required. Fixed by
   moving `re_derived` too (`union-run-FINAL.txt` is the correct reading).

4. **My C2 traversal arm resolved to a non-existent path**, so it read the
   already-named `override path missing` class instead of the confinement
   question. Fixed; the fixed run is the one quoted in §2.
5. **My first frozen-instrument comparison ran without `--repo`**, so both corpus
   instruments resolved their repo from the copy's own directory and returned
   `INCONCLUSIVE` / empty stdout — which would have read as "byte-identical" if I
   had only compared exit codes. Fixed by passing `--repo`; the `cmp` receipt in
   §3 is the corrected run.
6. **My C2 frozen-guard run doubled the guard path** (relative path resolved
   against the world cwd), so all six arms read a `can't open file` error as exit
   2 — a false "everything closes". Fixed with absolute paths; the corrected run
   is in §2's left column.
7. **An `EXIT=$?` after a pipe read `tee`'s status, not python's**, once reporting
   a red self-test as `EXIT=0`. Re-captured without the pipe; every exit code
   quoted in this report is from an unpiped run.
8. **I did not re-derive R1's three new doors** (cwd/receipt divergence,
   payload-chosen probe target, duplicate-id). They are recorded as R1's findings
   with attribution; my composite does not depend on them, but I did not
   independently falsify them either.
9. **I did not land T1's candidate**, though it closes every arm of my battery
   and preserves the live join. I chose not to: this seat's whole value is that
   the instrument under test was not touched by the seat that graded it, and a
