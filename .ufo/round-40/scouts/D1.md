# Seat D1 | deep-laundering-derived — round 40, loop A position 4

**Seat question.** Can a value be laundered through a row the census marks
derivable-but-scoped — i.e. can a payload scope out a row the committed scope file
**does** list while presenting a **fabricated census**, and does the driver's
recomputation catch it? (Bounds R1's F-2 boundary: two-artifact trust.)

**Answer.** **No, the recomputation does not catch it.** A payload that keeps the
four committed catalogue rows scoped out, but re-aims each row's probe at a
payload-created carrier and declares that carrier's truthful census, reads
**exit 0 / 24/24 / "all checks agree, both instruments green"** — byte-identical in
the report to the honest run except for the payload path it names. The driver
recomputes *faithfully*; it recomputes the payload's own claim, not the committed
truth. The seam is the probe's **`target`**: `recompute_probe` reads
`probe.get("target")` (`compare_harness_independent.py:490`) from the payload under
test, and `load_scope_file` (`:429-465`) returns the contract but pins no root —
`check_scope_probes` (`:556`) enforces only the contract's `kind` (`:607`). The
docstring at `:66` claims the probe is recomputed "from the substrate root the
committed file pins"; the committed file pins no root.

This bounds R1's F-2 rather than closing it: r39's closure is a **two-artifact
trust** — the committed scope *set* (which rows) and the payload-supplied probe
*evidence* (why). The first artifact is now load-bearing; the second is still
self-served. R1's F-2 rides the value channel into the same join; mine rides the
probe channel. Neither is named by C1's after-text.

## 3. The channel structure around the seam

The probe reaches the driver through two channels, first-non-empty wins
(`build_meta` `:1735-1741`): the top-level `scoped_out_probes` map, else per-record
`probe` blocks. Neither is cross-checked against the other. Measured on the landed
driver (`arms2.py`):

| arm | shape | exit |
|---|---|---|
| `map-real-record-fake` | map honest (real root), per-record fabricated | 0 |
| `map-fake-record-real` | map fabricated, per-record honest | 0 |
| `record-channel-divergence` | no map; `results` fabricated, `rows` honest | 0 |
| `map-empty` | map `{}` → falls back to the fabricated per-record channel | 0 |
| `map-only` / `record-only` | one channel populated | 0 |
| `probe-bare` | only `kind`/`target`/`observable`; `claim`/`falsified_by` stripped | 0 |
| `map-partial` | map carries 3 rows; the 4th only per-record | **2** |

`map-partial` is the inverse defect: the fallback is all-or-nothing (`if not
probes:`), so when the map is non-empty the per-record channel is **never read** —
a row whose probe exists only in the record channel gets no probe at all and is
rejected ("carries no probe block"), even though every row in the payload carries
one. (Measured arm: map carries 3 rows, the 4th only per-record → exit 2. The
mirror case — a payload honest in the record channel with one stray map probe —
would be rejected for the same structural reason, but I did not build that arm;
disclosed as unmeasured.)

The receipt cannot see any of this. Control vs laundered receipts are identical on
`scope_locks` (`{"committed_set": [4 catalogue rows], "probe_kind":
"rule-spread-census"}`), `scope_file` and `join`; only the independent input digest
differs, and the digest is of the payload the reader already distrusts:

```
$ python3 ... --receipt runs/control-abs.receipt.json   # and runs/fab-spread.receipt.json
scope_locks identical: True   scope_file identical: True   join identical: True
```

The seat question's "two-artifact trust" is therefore exact: artifact 1 (the
committed set) is checked; artifact 2 (the probe) is transported, recomputed
against itself, and receipted by digest only.

## 4. The bound: what the closure does catch

Filing the seam is not an argument that the r39 closure is worthless. Measured
green-to-red flips that hold: probe `kind` vs the committed contract (`kind-wrong`
→ 2); a relative target (`target-relative` → 2); a target that carries no candidate
block (`redirect-empty` → 2); a flat surface where every blind rule agrees
(`fab-flat` → 2); a declared observable that does not recompute (`fab-mismatch`,
`real-target-wrong-obs` → 2); a row scoped out that the committed file does not list
(A2's arm; the r39 self-test's own arms); a committed row deleted from the payload
(`delete-undec` → 2, "uncovered checks"); an honest derivation of a committed row
(`derive-honest` → 0, correctly — the comparison getting stronger). So the closure
holds against everything that does not require the payload to *name a surface*.
That is the exact boundary R1's F-2 sits inside.
