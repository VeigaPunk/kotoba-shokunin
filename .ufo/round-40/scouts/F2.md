## DEFECTS (mine, disclosed)

   (a) XML namespace — `el.tag != "code_block"` matched nothing under the default
   namespace, so every shape read `cmark=[]` and I first saw 10/10 "mismatches";
   fixed with a namespace-tolerant tag test. (b) The HTML sentinel was a bare
   `"row"` string, which appears in ordinary prose — the `<pre>` test needed the
   row's own marker (`knowledge/b.md`). (c) The independent instrument has no
   `--no-baseline` flag; my runner passed it and got rc=2 with `unindexed=None`,
   which I first mis-read as "fail-safe/other". All three fixed and re-derived;
   the wrong runs are in the draft history, not cited.
2. **[OPEN, LOW, introduced by my clause, zero live incidence] The flat cap removes
   an accidental shield on the independent gate for *indented-code* coverage rows.**
   The independent gate harvests an indented table row (its `coverage_cells` strips

   a 4-column fence-like block made that row opaque on both gates, hiding the
   divergence. After my cap the independent gate reads such a row as a live promise
   again:
