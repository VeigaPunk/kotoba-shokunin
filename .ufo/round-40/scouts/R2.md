### 10. NEW arm (mine) — absolute argv is kept lexically raw; a `..` spelling of another row's own file is silent-green

`main()` (`:344`): `path = path if path.is_absolute() else (repo / path).resolve()`.
`override_drift` (`:291`) compares `path == canonical[other]`, and `pathlib` equality
is **lexical** — it does not normalise `..`. So the *same file*, spelled two ways,
gets opposite verdicts:

```
$ python3 - <<'PY'   # r2 precision probe, live guard a4efe1a7
relative argv 'verifiers/../verifiers/stub-instrument-2.py'          rc=2  FAIL registry override repoint: stub -> .../stub-instrument-2.py (canonical instrument for stub2)
absolute argv '/tmp/.../w/verifiers/../verifiers/stub-instrument-2.py' rc=0  PASS stub observed=7 floor=3
```
Identity is not in question — same inode, same device, same `realpath`:

```
identity: SAME FILE (st_ino+st_dev) = True
identity: os.path.realpath equal   = True
identity: Path(lexical) == Path(canonical) = False
identity: Path(canonical).resolve() == Path(lexical).resolve() = True
```
**Why this is a new cell and not E2's A14/A16.** E2's `..` arms are all *relative*
(`A13/A14/A16/A16b`), where `(repo / path).resolve()` normalises and the predicate
fires. The absolute branch is `..`-blind. E2's absolute arms (A3/A4/A6/A11/A12) all
name a target by a spelling that is already canonical or by a copy/link. This arm is
the **intersection neither seat covered**: absolute + `..`, landing on the other
row's *own file* — not a copy, not a symlink, not a hardlink, so the "a probe may
point a row at a stub or a temporary copy" affordance does not apply and the
docstring's "an override aimed AT another pinned instrument's canonical path …
fails loudly" is simply false for it.

Fix shape (one line, same predicate): canonicalise both sides of the comparison,
e.g. `path = Path(overrides[name])` → resolve lexically (`os.path.normpath`) or
compare `path.resolve()` against `canonical[other]` — plus a confinement clause
(`Path(repo) in path.resolve().parents`) for §9. **No live incidence**: all 8 live
row paths are regular files with no `..`.
