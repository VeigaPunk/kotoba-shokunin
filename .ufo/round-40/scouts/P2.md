## 2. The fix (landed)

`verifiers/compare_harness_independent.py`, three additions:

* `_channel_maps(payload, where, value_keys)` — parses **every** published
  channel (record list or dotted map) into `{id: (value, status)}`; a channel
  whose shape the contract does not define is named, never skipped. A repeated
  id inside one channel carrying two values is named too (that shape was
  invisible at HEAD: last-write-wins discarded the first record silently).
* `_reconcile(channels, where)` — cross-checks the parsed channels: value
  divergence (canonical, so `7` vs `7.0` and `True` vs `1` are divergences, not
  `==` coincidences), status split, and channel membership. Returns the joined
  map.
* `parse_independent` now routes through them (statuses are read from **every**
  channel, and a split is itself a failure); `parse_live` does the same under its
  own `LIVE_VALUE_KEYS = ("observed",)` — the live side's value contract, so a
  live record's `expected` is not compared against a key the live contract never
  defined.

Message classes, named: `channel divergence for <id>`, `channel split for <id>`,
`channel membership differs between <a> and <b>`, `duplicate id <id> in <chan>
carries two values`, `<chan> is a mapping that is not keyed by check id`.

## 5. No new door introduced (the claim's own requirement)

Cross-channel reconciliation must not itself be bypassable. Each bullet measured
directly, not inferred:

* **Dropping the shadow channels is not an escape.** A payload publishing *only*
  `results`, with `omp.offered.skills` divergent, reads
  `exit 1 — disagreements: omp.offered.skills (mode=equal: expected 999,
  observed 7)`: with nothing to reconcile against, the ordinary join still
  catches it. The honest form of the same payload stays exit 0.
* **The live side really reconciles.** A live payload that grows a second channel
  (`rows`) carrying `999` for `omp.offered.skills` fails closed:
  `exit 2 — live: channel divergence for omp.offered.skills: results=7 but
  rows=999`. This is the `parse_live` lock, and it is load-bearing, not
  decorative.
* **The live value contract is respected.** A live payload carrying a foreign
  `expected` (12345) *beside* its own `observed` still reads `exit 0`, because the
  live side reconciles under `LIVE_VALUE_KEYS = ("observed",)` — comparing it
  against `expected` would invent a contract the live instrument never had.
* `--joined-only` runs (scope-out channel dropped) leave every F-3 arm's verdict
  unchanged.
* The honest live payload is unchanged: `protocol 24/24; strict 20/24;
  adjudicated 4; scoped-out 4; secondary 20/24`, exit 0.
