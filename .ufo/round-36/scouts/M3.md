## Defects
1. **Extension-locked tokenizer (unnamed class).** `UFO_POINTER_RE` requires `*.md`; a dead report pointer ending `.txt` or `.MD` is invisible -> exit 0, `dead=0`, `report_total` unchanged (probes C, I). No counter records the drop.
2. **Index census is fence-blind (P3's class, confirmed).** `file_column_tokens` never tracks ``` ``` ``` fences: fencing a live row keeps it counting (O2 exit 0, unindexed=0 — the file's only coverage is inside a fence); fencing a dead row still counts it as a promise (N/O3 -> missing+stale fire). Fenced rows are live in both directions.
3. **Glob-replacement escape.** Replacing all coverage rows with `knowledge/*` + `lessons/*` passes (P2 exit 0, unindexed=0). `knowledge/*.md` leaves the `.json` companion unindexed (P exit 1), so `*` is the evading form.
4. **Fault harness gap.** `fault_injection_corpus.sh` has no fence class: fault-d1/d2/e plant dead/untracked rows but none fenced, so P3's shape is unrepresented in the "all must-fire" set even though the instrument is blind to it.
