## Findings
- **The defect is real and A/B/C2 all close it.** orig flips 17/28; A, B, C2 flip **28/28** twice, every DRIFT naming the id. Gained = exactly the 11 zero/positive pins; the 17 equal/at_least pins unchanged. Three independent derivations (Z2, Z3, mine) agree on 28/28 — the dead-code reading at `:560/563` is not a measurement artifact.
- **No PASS line changes on the live tree.** stdout byte-identical orig vs A/B/C2 (`cmp`), 28/28 exit 0; verdicts and `observed` identical. Only `--json` `expected` moves, on exactly the 11 rows: `"0 / empty"`→`0`, `"> 0"`→`7` — the pin becomes visible to a JSON consumer. Not a regression: the strings had no consumer (`"0 / empty"` elsewhere is `verify_corpus_integrity.py:601`'s separate `corpus.*` ids).
- **Zero-mode semantics preserved, both arms.** With a baseline: `observed==expect==0` PASS, `expect:null`/row-deleted DRIFT (fail-closed, was silent PASS). Without a baseline: `--no-baseline` output byte-identical, exit 3, zero rows still PASS — no regression to fail-closed.
- **Minimality.** A is 14 lines changed, 0 net (pure reorder, no new branch, no comment). B adds one line of strict typing — unnecessary, and it *creates* a false-DRIFT: `expect:0` on the bool-observed `oc.roots.plugins_cache` exits 1, where A passes. A is the minimal fix.
- **A's one residual, closed cheaply by C2.** A's positive arm is `value >= want`, so `expect:0` on `omp.descriptions.over_cliff` passes vacuously (exit 0, same on orig/B). C2 adds `want > 0` to the positive arm only (2 lines): that probe flips to exit 1, live still byte-identical, matrix still 28/28, `at_least` untouched.
- **Durability gap is real, and the graft works.** `--self-test` on the dead-code tree is 0/10, so it is no evidence for Z. A baseline-arm graft (clean PASS + 28 corrupt→DRIFT) yields 11 failures on the dead-code tree, 0 on A/C2 — it would pin the fix against re-breakage.
- **Sibling gates:** `check_assertion_floors.py` 6/6 PASS; fault harness OK; six live gates exit 0 on orig and patched — no regression.
