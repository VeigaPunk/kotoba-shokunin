## Defects named

   in index and worktree; the other six verifiers are `100755`.
   `./verifiers/check_substrate_pins.py` -> Permission denied. The one verifier
   guarding substrate identity is the only one not directly runnable.
2. **Unwired guard (persists).** Zero invocations from gates, checklists, or hooks.
   The round-21 lesson ("an unenforced pin is the defect") is half-closed: pins are
   enforced only when a human remembers to run the guard.
3. **Guard is unguarded (persists r26-S10 D3).** No pin covers the guard's own
   sha; per r26-S10, a tampered copy leaves harness + surfaces green.
4. **SKILL.md self-test surface misdescribed (new; ground r26-S7).** SKILL.md:465
   says `--self-test` runs "over `verifiers/fixtures/pins/`" — false: the guard's
   only "fixtures" occurrence is its `--help` string; the self-test is tempfile +
   inline payload; nothing in `verifiers/` opens `fixtures/pins/` (mini.bin,
   mini2.bin, tripwire.bin are committed tripwires read by nothing).
5. **Pin coverage 2/7 (new).** omp + opencode are pinned; kimi, codex, cursor,
   grok, devin are live on this host (`/home/vgpnk/.kimi-code/bin/kimi`,
   `…/fnm_multishells/…/codex`, `/home/vgpnk/.local/bin/cursor`,
   `/home/vgpnk/.grok/bin/grok`, `/home/vgpnk/.local/bin/devin`) and unpinned.
   Mitigation: the guard's discovery regex maps a hypothetical `kimi_binary_*`
   pin to UNSUPPORTED exit 2, so extension is loud, not silent — but today those
   five can be replaced unnoticed by every gate.
