Result is **identical on all revisions** (`R38BEFORE`, `LANDED`, `INFLIGHT2`, `INFLIGHT3`,
`FINAL`):

| arm (argv form) | verdict |
|---|---|
| copy / symlink / hardlink of **another row's target**, absolute argv | **rc=0 silent-green** |
| copy of another row's target, relative argv | rc=0 silent-green |
| symlink to another row's target, relative argv | rc=2 `override repoint` (named) |
| the other row's canonical path, relative argv | rc=2 `override repoint` (named) |
| own canonical path | rc=0 (allowed by design) |

Mechanism, at source (`main()`, both revisions, e.g. `verifiers/check_assertion_floors.py:341-343`):
`path = path if path.is_absolute() else (repo / path).resolve()` — an absolute argv path is
kept **raw**, so `override_drift`'s `path == canonical[other]` comparison (canonical is
`.resolve()`d) misses a symlink/hardlink/copy that *points at* another pinned instrument.
This is **pre-existing** (identical on `R38BEFORE`) and the `--script`-copy affordance is
explicitly documented in the trust boundary ("a probe may point a row at a stub or a
temporary copy"), so per my seat criterion this arm is **documented, not a regression**;
the docstring's narrower claim ("an override aimed AT another pinned instrument's canonical
path … fails loudly") holds only for the path string, not for a link to it.

Path confinement (`out/CONFINE-ALL.txt`, `out/CONFINE-FINAL.txt`, regenerated with
`python3 confine.py --guard frozen/check_assertion_floors.<REV>.py --work scratch --tag <REV>`):
a hermetic world declaring an absolute path outside `--repo` **and** a `../` traversal both
read `PASS stub observed=3 floor=3` rc=0 on all revisions measured (`r38before`, `landed`,

pre-existing, unchanged, and the trust boundary is documented in the registry comment
