## Application notes

- One row, appended after Q74; `supersedes` stays `—` because the row is a refinement of Q61 in Q62's "Q14 refinement, not a new rule" idiom, not a replacement. Q61's "an object absent from both stays unresolved" therefore binds *in-set* objects; this row adds the grammar class for citations that name a repository outside the declared set.
- The criterion is grammar-level and implementation-agnostic: it fixes *which* markers count, that the URL form must be unambiguous (exactly one named pair, else fail closed), and *what* the class must preserve (INFO naming, counted detail naming the marker repo, the unmarked red path, and no reclassification of a resolvable in-set object). It does not pin a report-line spelling.
- The candidate world is evidence for the criterion and must NOT be stacked with E05's patch in one integration; the landed patch is E05's. In that world `commit_total` still counts a classified citation once (46 at base, unchanged), so the `commit_total` baseline refresh is driven by the r79 rows, not by this class.
