Probe: 40 single-point mutants of a scratch copy of `verifiers/check_cn_vendor_surfaces.py`
(blob `89b8f8f027181337898fe095226cb6de0a2818a6`, identical at base `b10bcbc6…` and plan commit
`2c566223…`), each run through its `--self-test` (56 worlds / 161 assertions, baseline exit 0).
17 killed / 23 survived = kill ratio 42%. Per-mutant evidence: `Kb79MT02.mutants.log`,
`Kb79MT02.verdicts.tsv` (same directory). A survivor is a coverage finding: the template's
fixture battery cannot tell the mutated counter from the frozen one, so the NEW counter
(`check_allowed_tools.py`, seat Kb79X01CounterBuild) must carry the arm AND add the listed
fixture world, or the arm is decoration. One-line fixture per survivor below.

## Evasion arms (a mutant here is a way a seat could pass without the page)

1. **Host equality -> substring** (mut24: `host == h.lower()` -> `h.lower() in host`, both branches).
   `docs.trae.cn.evil.io` and `evil-docs.trae.cn` satisfy the substring read; no fixture has a
   hostile host. Fixture: registry URL `https://<frozen-host>.evil.io/page` on a surface whose
   pin is the bare host must fail with "no URL on <surface>'s pinned host(s)".
2. **Whole path segment -> bare prefix** (mut25: `path == prefix or path.startswith(prefix + "/")`
   -> `path.startswith(prefix)`). `…/moonshotai/kimi-cli-docs/…` passes the
   `github.com/moonshotai/kimi-cli` pin; this is exactly the round-79 C6 sibling-host control
   (`raw.githubusercontent.com/badlogic/pi-mono-evil`). Fixture: registry URL
   `https://<host>/<pin-path>-evil/docs/skills.md` must fail the `<host>/<pin-path>` pin.
3. **Dot-segment guard dropped** (mut26: the `.`/`..` segment rejection in `host_ok` removed).
   `/a/pin-path/../evil/page` satisfies a bare-prefix read. Fixture: registry URL containing a
   `/../` segment must be rejected even though the string prefix matches.
4. **Quote-in-own-snapshot -> any-snapshot** (mut28: `quote not in text` -> `quote not in " ".join(all pages)`).
   Quote laundering across the row's other snapshot; round-79 (d) says "occurs in its own snapshot".
   Fixture: a surface's located quote present only in a DIFFERENT cited id's snapshot must fail
   "not found in its pinned snapshot".
5. **Manifest duplicate-digest conflict dropped** (mut27). A manifest pinning one file to two
   digests is accepted, last line wins. Fixture: manifest with the same snapshot name pinned to
   two different digests -> exit 2, never a pass.
6. **HTTP status unchecked in the anchor record** (mut37: `HTTP 200` -> `HTTP \d+` in `FETCHED_RE`).
   An anchor recording `HTTP 404` passes the (e) anchor checks. Fixture: anchor line
   `fetched <ISO8601>Z, HTTP 404, <N> B, sha256 <hex>` must flag "carries no 'fetched … HTTP 200 …' record".
7. **Multi-named-pin ambiguity -> first wins** (mut34: `len(named) == 1` -> `named`). The entry
   naming two pinned snapshots for one cited id silently resolves to the first. Fixture: entry
   naming two distinct manifest snapshots on one cited id's lines -> exit 2 "ambiguous".
8. **PROVINCE/`## Core` vendor match word-boundary -> substring** (mut30). `Zhipux` counts as
   `Zhipu` in the bullet. Fixture: a Core bullet naming a surface inside a longer word must not
   count that surface (round-79 (f): the one Core bullet names the entry and >=3 surfaces,
   word-bounded).
9. **URL trailing-punctuation trim dropped** (mut35: `rstrip(TRIM_CHARS)` removed). Registry or
   source-line URLs written with a trailing `.`/`,`/`)` stop matching path pins — honest rows
   break, and the binding check loses its trim symmetry. Fixture: a cited row URL carrying a
   trailing period must still bind to its page (template trims `.,;:!?)]}'"`).
10. **`clean()` backtick/emphasis strip dropped** (mut22). An entry table row whose first cell
    writes the surface name as `` `Claude Code` `` or `*Claude Code*` stops naming it — a styled
    honest row goes uncounted. Fixture: an entry row whose first cell backticks the surface name
    must still be recognized as that surface's row.
11. **Entry-trio order scan-anywhere** (mut38: `field()` scans the whole entry instead of the
    position right after the `source:` block). `verified-at:` placed BEFORE the source: lines is
    accepted; round-79 (a) freezes the order "source: lines, then verified-at:, then recheck:".
    Fixture: entry with `verified-at:` above its `source:` lines must flag "no verified-at: line
    after its source: lines".

## Weakened-bound arms the battery cannot isolate

12. **MIN_KEY_TOKENS 2 -> 1** (mut29). The template's only two-token world also starves
    MIN_TOKENS, so the key bound is never isolated. Fixture: entry row with 3 tokens, 1 root,
    only 1 key (e.g. root + `xtuff` + `name`) must fail "1 frontmatter key token(s)".
13. **CJK/ASCII word-boundary masked by the existential token read** (mut04: `[A-Za-z0-9_]`
    boundary -> `\w`). The template's CJK world expects 4 of 4 either way, because the row's
    OTHER cited snapshot carries the same root token without CJK abutting. Fixture: make the
    CJK-abutting snapshot the row's ONLY page carrying the root token, expect 4 of 4 — a `\w`
    mutant then fails it. Keep the ASCII-boundary read (CJK pages are in the round-79 population).
14. **rendered(): HTML-comment stripping dropped** (mut01). The template's hidden-row world puts
    the row alone between non-`|` lines, so with stripping dropped it becomes a header-only
    table block and is still invisible — both readings agree. Fixture: TWO surface rows hidden
    in ONE HTML comment; with stripping dropped the second surfaces as a data row and the world
    must still read "0 vendor-table row(s) name <surface>".
15. **rendered(): fence stripping dropped** (mut02, same shape as 14). Fixture: two surface rows
    hidden in one fenced block, expecting "0 vendor-table row(s)".

    the source-line head set (dedup + the `located quote` split), so no world can fail from

    fails via the cited-ids-subset check, so the explicit note is message-quality only. Keep for
    finding quality; no fixture needed.
