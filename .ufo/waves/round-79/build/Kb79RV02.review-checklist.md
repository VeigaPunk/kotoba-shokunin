## 3. What the instrument-size guard counts (exact)
`LINE_CAP = 40` (verifiers/check_tip_battery.py:111). The guard runs
`git diff --numstat --no-renames <base> <rev> --` over EXACTLY the six BATTERY scripts
(:145-152), sums ADDED lines over all six together and DELETED lines over all six
together, and fails if either total exceeds 40 (:309-320). It also fails an absent
instrument (:310-311) and a binary instrument diff (:313-315). The deletion side is
what makes the stub shortcut ("replace a gate with `sys.exit(0)`") fail — a two-line
stub deletes ~a thousand lines (docstring :53-58, self-test stub world). Because
instrument-pin (§2) allows no byte change at all this round, any patch line inside
these six files fails regardless of size; the cap binds only when the pin list is
legitimately extended (as r76 did for the floors-guard bump).
