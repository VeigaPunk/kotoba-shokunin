## Proposed fixes (not applied; the counter is frozen)

1. S4: add `"--tmpfs", "/run"` (and `/var/run` if it is not a symlink) to the wrap at :280. Better still, build the sandbox from an allowlist of read-only binds.
2. S5: in `guard_g4`, set `root = os.path.realpath(Path(offered[name]).parent.parent)`, fail any offered path that has a `..` part, match per segment (`len(parts)` equal and `fnmatchcase` on each part), and limit `{cwd}/` expansion to cwd and its ancestors below `$HOME`, as omp's walk-up does.
3. S6: catch `subprocess.TimeoutExpired` at :294 and raise `Inconclusive`.
4. E1: wrap the import-time plugin scan in `try/except (OSError, AttributeError, TypeError)`, or compute it lazily inside `discover_skills`' caller.

## Verdict

S5 is a C1 fail-open in the addendum-1 counter: G4 accepts an unresolved `..` path, and `*` crosses `/`. A world reading 132 names from a root omp does not read scores `215 of 215`, G1–G4 PASS, exit 0. S4 leaves a root-equivalent sandbox escape through `/run/docker.sock`. ExecModel's candidate uses neither.
