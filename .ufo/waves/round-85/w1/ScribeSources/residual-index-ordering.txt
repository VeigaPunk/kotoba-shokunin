## proof of the index semantics this rests on

  `git ls-files` lists the git INDEX, so a file that is staged but not yet committed
  IS listed. Probed in a throwaway repo under this seat's scratch:
    - file on disk, NOT staged  -> git ls-files lists it: NO
    - after `git add <file>`    -> git ls-files lists it: YES
  So the stale -> 0 transition is exactly the L1's `git add` of the file.
