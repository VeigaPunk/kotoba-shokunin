## Adversarial path matrix and receipt race

The preserved `probe_candidate_fixture_paths.py` replay ran nine CLI cases against the pinned candidate. Three relative-path attacks from a planted process CWD (including process-CWD symlink file/directory variants), plus an absolute honest-scope override, were rejected with exit 2 and named `laundering`. Five explicit planted-scope controls—relative scope under `--cwd`, symlinked scope file/directory and `--cwd` root, and an absolute symlink argument—passed at 1/1. Every successful control's receipt path and SHA-256 matched the resolved path and bytes used by that case.

`probe_candidate_receipt_race.py` opened the planted scope and atomically replaced that path on the observed `inotify IN_OPEN` event, before receipt generation. With 1,500 carrier files, the join exited 0 at 1/1. The initially read/enforced scope digest was `d86fd2f987b06f40541d6985f71e26098e5341b5b420fda346f1ca0fd5aeb770`; the path contained replacement bytes `dc9a70174698d7fc16fd510433f5bf22937b5b7393bc72fb02d0e4f1c2605868` after the run. The receipt retained the initially enforced digest and the resolved scope path. This confirms exact-byte receipt behavior for this replacement timing; it does not make the scope path or its author trusted.
