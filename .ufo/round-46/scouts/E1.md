The last case is a trust-boundary result, not a bypass of the default scope file: `--scope-file` permits the caller to select a custom file, and the comparator treats its `scope_out` map as authoritative. The receipt digest proves which bytes were used, but the comparator does not authenticate those bytes against Git `HEAD`, a trusted digest, or a signature. A self-computed digest cannot establish authority. The metadata-only forged set is ignored; changing the actual `scope_out` map changes the joined scope.
