`extract_json()` calls ordinary `json.loads()` both for the whole text and for the balanced-object fallback (`verifiers/compare_harness_independent.py:207-243`). Once decoded, no gate can see the earlier member. The variants therefore reach the comparator's channel and field checks as clean, matching records. This is one decoder-level door, one function wide: reject duplicate members recursively in both JSON-load paths and return a named exit 2. No source change was made by H04.

**Unicode identity is an unresolved conditional residual.** The synthetic live and independent records each carried NFC `unicode.café` with value 1 and NFD `unicode.cafe\u0301` with value 2. Both strings normalize to the same NFC id, yet the comparator returned exit 0 at 2/2. Record ids are accepted as strings by `_record_id()` (`:265-275`) and joined as exact strings; no normalization or collision rejection occurs. If the contract treats canonically equivalent ids as one identity, this is a second false-green door. If ids are intentionally opaque exact strings, the observed join is consistent with that policy. No normalization policy was found in the comparator contract, so this remains an unclassified boundary rather than a claimed closure.

The other requested shapes did **not** produce a contradiction under the comparator's exact-key semantics:

- `prefix.item` and `prefix.item.extra`, with distinct values, joined at 2/2 across `results` and the dotted `checks` map. `_dotted_map()` accepts both as separate dictionary keys (`:259-263`); reconciliation tests exact membership (`:408-435`), not prefix relationships. No prefix collision was observed.
- Record ids `results`, `rows`, and `checks`, with distinct values, joined at 3/3. `CHANNEL_KEYS` are top-level payload members (`:246`); these ids were values inside nested records, so the parser did not confuse the two levels. Records do not currently enforce the dotted-id regex; if the intended schema requires every record id to be dotted ASCII, that separate validation is absent, but this probe found no channel collision or contradiction.
