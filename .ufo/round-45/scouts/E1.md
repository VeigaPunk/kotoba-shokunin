## Source path and limits

The frozen source makes the split explicit: `load_scope_file` reads `Path(path)` directly (`.ufo/round-45/drafts/e1/compare-13b6d791.py:779-807`); `check_scope_probes` validates payload-declared scoped rows against the committed set (`:898-977`); receipt hashing resolves a relative scope path under `--cwd` (`:1407-1412`). The exact CWD replay therefore leaves one proven open door: relative scope selection is controlled by process CWD while the receipt attests a different file. The absent-row case is an additional accepted-but-inert scope-file coverage gap; unsupported contract kind with active rows is closed.
