## Findings
Silent skip confirmed. The key is not merely unchecked, it is never enumerated: it appears in no stdout/stderr line, no `--json` record, and not in the denominator (summary reads `3/3`, never `4/4`).

Site: `verifiers/check_substrate_pins.py:146` (discovery gate), dead-end at `:153`:
- `:145-147` `for key in sorted(ma): if key not in keys and DISCOVER_RE.match(key): keys.append(key)` — the only place a non-contract key enters `keys`.
- `DISCOVER_RE` `:75` = `^(?P<prefix>[a-z0-9_]+)_binary_(?P<kind>[A-Za-z0-9]+)$` — anchored, no `\s*`; a padded key fails `.match()`, the `if` skips it, no verdict entry is built.
- `:152-153` re-matches only keys already in `keys` — padded keys never arrive.
- `:161-163` mis-case check uses `casefold()` only, no `strip()`.
- No trim/normalization anywhere (`grep 'strip|trim|lstrip|rstrip'` hits only `:446`, a self-test stdout check).

Escalation past M4: the never-silently-skip promise for unregistered substrates (`:172-176`, exit 2) is bypassed by one leading space -> exit 0; a typo'd stray pin can be parked silently.

## Defects
1. `:146` padded pin-shaped key silently skipped (exit 0, absent from counts) — space, tab, NBSP.
2. `:146` padded *stray* substrate key evades UNSUPPORTED (0 vs 2 unpadded).
3. `:161` case-fold comparison has no whitespace normalization, so padding also defeats the mis-case path.
4. Asymmetry: trailing-`\n` keys ARE discovered via `$` and reported; leading/trailing-space keys are not.
