## Findings

1. **The index is complete and both instruments agree.** 53 tracked; primary and
   independent both report unindexed 0 / stale 0 / missing 0 and exit 0, with the
   same nine numbers (tracked 53, report 36/0, commit 27/0/0). My own derivation
   (command 2) reproduces 53/53 with brace expansion — the three
   `round-{1,4,5}-aggregator-audit.md` rows are the only brace forms and they
   resolve. **No unindexed file.**
2. **README rows resolve.** 50 coverage-map data rows, 73 File-column tokens, 0 dead
   (commands 2/3). The 117 "dead" hits in the all-cell sweep are Basis-column prose
   tokens, not path claims — the instruments correctly scope to column 2.
3. **The 67-vs-69 token-count difference is definitional, not a disagreement.**
   Primary `index_patterns 67` (excludes placeholder/host-absolute tokens, min-4
   cell split); independent `index_tokens 69` (no exclusion, min-5 split). The two
   extra tokens (`../verifiers/fixtures/pins/` and
   `…/checklist/command-heredoc-tilde{,-dead,-misterm}/`, lines 44/57) both end in `/`,
   so the primary filters them as directory patterns; neither counts either as
   unindexed. Known adjudicated divergence (round 12), not a defect.
4. **Claim R: the stale guard is one literal in the embedded code; the JSON is
   already correct.** `sibling-citation-routing-round16.md:154` hardcodes
   `02ccf1b310f791…`; the companion JSON `instrument.sha256` already reads
   `15d0aa16d549…` with `sha_superseded_from`. Every published replay mode dies on the
   worktree-module hash (command 6), matching scout W05. **Variant B is strictly
   stronger** than a new literal: it flips on real instrument drift (append a byte)
   *and* JSON-pin tampering, where variant A flips on neither. One-line change;
   siblings untouched; self-test 1504/0 unchanged.
5. **Claim I: crash root cause is `:313`.** `analyse_pointers` opens each of the 52
   tracked `.md` files with no existence check; the primary classifies the same
   deletion via `Inconclusive` (`:486`). The independent script already has the
   `EnvError` → exit 2 path (`:57`, `:770`) — the pointer loop never routes into it.
   A 2-line patch (command 8) restores parity. The crash class is `.md`-only (`analyse`
   uses `corpus_markdown`), so a deleted `.json` crashes neither (command 5), and the
   README case is already handled by the `EnvError` index path.
