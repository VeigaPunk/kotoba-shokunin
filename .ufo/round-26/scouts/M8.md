## Findings

- **The intended red probe holds, on both the published fixture and the live binary.** Deleting
  either OC-1 anchor (`verifiers/verify_surfaces.py:358-359`, consumed at `:412-414`) yields exit 1
  with the class *and* the rule named, per `check_opencode_extract` (`:641-671`). Live anchors are
  present: `ConfigInstructionPlugin.projectSource` ×2, `targets:["AGENTS.md"]` ×1 (min line distance 0,
  same chunk). Determinism holds; self-test is 75 assertions at HEAD, matching the round-21/24 records.
- **The co-presence weakness is closed by the unmatched-rule clause**, not by the anchors: a dump
  carrying the two OC-1 literals in unrelated paths still FAILs. That is stronger than the round-25
  X10 slice established (which removed only the fn name).
- **The controls are anchor-greedy in the wrong direction:** the guard cannot tell a live loader
  anchor from a doc/comment occurrence of the same literal.

## Defects named

1. `verifiers/verify_surfaces.py:412` — `OC_PROJECT_FN in dump and OC_PROJECT_TARGETS in dump` is a
   raw substring test with no comment/context filter. Taking the clean fixture, deleting both OC-1
   anchor *lines* and re-adding the identical literals inside `#` comment lines gives exit 0 and
   `6/6 rules` — the red probe that guards this rule can be turned green without restoring the real
   anchor. Evidence: `/tmp/m8/fpc.txt` -> exit 0, all seven checks PASS. Severity: calibration, not
   live (the `strings` dump has no `#` comments), but the fixture *is* the control.
2. `verifiers/verify_surfaces.py:412` (same line) — no token boundary: `XConfigInstructionPlugin.projectSourceY`
   matches OC-1. Evidence: `/tmp/m8/fpb.txt` (whole gate exit 0) and `/tmp/m8/fp5.txt` vs a
   one-class mini baseline (OC-1 matched, not reported). Real minified identifiers drift by exactly
   this kind of affix, so a renamed callee could keep OC-1 green.
3. `verifiers/verify_surfaces.py:994` — the default baseline is `<repo>/verifiers/surfaces-baseline.json`,
   so the natural minimal invocation `--repo verifiers/fixtures/surfaces --check surfaces.opencode_extract`
   (the shape `--self-test` itself uses for `--repo`) exits **3** with `baseline not found:
   …/fixtures/surfaces/verifiers/surfaces-baseline.json`. Minor/usage: needs `--baseline` spelled out,
   which the round-25 X10 record's published argv does not do.
