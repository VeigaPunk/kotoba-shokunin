## Findings
- **The class is live at HEAD**, identical to F1's round-24 pin `430fe289…`; `:313` is the surface, `:346` the same class shadowed by analysis order.
- **Both designs close the same five variants with the same exit code** — the A/B is a wash on behaviour; the difference is shape. B is smaller and cannot be outrun by a later read site; A is local per reader but must be re-applied per new site.
