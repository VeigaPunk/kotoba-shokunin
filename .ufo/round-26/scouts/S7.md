## Findings

1. **Fixture tree complete and self-consistent.** 174 tracked == 174 on disk; no
   untracked/modified fixture; the sole zero-byte file and the one dir without
   `map.json` (`checklist/missing-map/`) are both deliberate.
2. **All six self-tests green at HEAD** (46/75/1504/88/52/10, all rc=0),
   reproduced on a clean archive extract — not worktree artifacts.
3. **`checklist/` (145 files, 71 cases) is fully load-bearing:** the `CASES`
   table (`verify_skill_checklist.py:1351`) has exactly 71 entries matching
   exactly 71 dirs; every `SKILL.md` is opened. Deleting all `surfaces/` fixtures
   drops that self-test from 0/75 to 74/75.
4. **DEFECT (new): `verifiers/fixtures/pins/` is orphaned.** All three files are
   opened 0 times by `--self-test` (strace) and by the live run; no code in the
   repo reads `fixtures/pins/`. The self-test synthesizes its own payload inline
   (`check_substrate_pins.py:302`), and committed `mini.bin` is byte-identical to
   it — a redundant copy. Deleting all three leaves `0 failure(s) over 46
   assertions` and `OK 3/3 pins hold` unchanged.
5. **The tripwire assertion is unenforced.** `tripwire.bin` is the only 0755
   fixture; its documented job (corpus record, round 23) is to make
   hash-never-exec an assertion, which needs a reader failing when `EXECUTED`
   appears — none exists. The inline tmp `mini.bin` never is 0755.
6. **Doc drift follows from D1.** Four live files assert the self-test runs
   "over `verifiers/fixtures/pins/`" (`SCORECARD.md:124`, `SKILL.md:465`,
   `LOG.md:1231`, `corpus/README.md:57`, plus the knowledge record) — true of the
   dir's existence, false as a description of what the run reads.
7. **Pre-existing, re-confirmed:** `surfaces/inventory-kind-drift.md` orphaned
   (never opened, deletion silent) yet still a working probe (command 6).
