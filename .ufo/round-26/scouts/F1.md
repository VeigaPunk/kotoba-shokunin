## Findings
- **The class is live at HEAD and unchanged since round 24.** `430fe289…` is exactly the sha
  pinned at `corpus/knowledge/independent-verification-round12.md:16` and in H8's round-24 table,
  so M8's round-21 `:313`/`:346` defect survived rounds 22–25 untouched.
- **Exact reproduction, both instruments.** Independent: exit **1**, traceback terminating at
  **`:313`**, zero bytes of verdict output. Primary: exit **2**, one `INCONCLUSIVE:` line. The
  `:29` docstring contract (`0` clean, `1` violation, `2` environment unreadable) is violated —
  a crash is reported as exit 1, indistinguishable by exit code from a real violation.
- **Four crash classes, not one** (H8's F1 re-confirmed at HEAD): absent path, dangling symlink,
  directory in the file's place, unreadable permission — all four land on `:313`;
  `README.md`-as-directory lands on `:205` via `:243`.
- **`analyse()`'s gate is why `:205` is reachable.** `:385` uses `os.path.exists`, true for a
  directory, so `corpus/README.md` passes and `coverage_cells` dies at `:205`. `:202-203`'s
  `EnvError("corpus/README.md missing")` is shadowed by `:385` and dead on every reachable path.
- **The self-test cannot detect the class** (52/0 on a crashed tree) because every case builds its
  own fixture index — which is why H8's sketch adds two env-gate cases.
