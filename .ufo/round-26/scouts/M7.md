## Findings

**F1 — Class (a) is genuinely gated, both instruments, both directions.** Must-fire rows carry
exit 1 + the intended check id in the primary and non-zero in the independent; sites agree
line-for-line (`round-3.md:37`).

**F2 — The (f) blind-spot assertion is vacuous on its count leg.** `:290` and `:293` both call
`json_field "$w" "observed.corpus.report_total"` — the same `out.json` written at `:141` by the
`--no-baseline --json` run. `out-baseline.txt` (`:291`) is written and **never read**, so
`base_total` re-parses `blind_total`; `[ "$blind_total" = "$base_total" ]` reduces to `x = x`
(debug: `35 == 35`). The row still prints `PASS(blind-spot documented: --no-baseline exit 0;
baseline-mode exit 1)` — a green whose parenthetical cites only the exit leg.

**F3 — The independent column gates exit codes, not independence.** The substitution probes show
the gate is two-sided only for constant stubs: always-green is caught by the must-fire rows,
always-red only by (g). A 5-line alias passes `ALL PASS`; "gates both instruments" is accurate
about exit codes and silent about the property that makes the second instrument evidence. No
independent-verdict content is parsed: `drift_ids` reads only `out.json`, the primary's.

**F4 — Class (a) demo is byte-clean and cheap.** 2.9 s full harness, ~0.3 s per instrument;
clone state after all probes is the untouched checkout. No writes outside `/tmp`; live repo HEAD
and worktree unchanged.
