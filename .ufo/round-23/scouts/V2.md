## Findings

**F1 — the +1 s probe reds all three, pin-side and substrate-side; sha pins stay PASS.**
Baseline-side (`b-mtime-plus1s`, sha pin untouched):
`FAIL omp_binary_mtime expect=2026-10-16T05:15:12.226207850-03:00 live=2026-10-16T08:15:11.226207+00:00`
+ `DRIFT 1/3 pins failed: omp_binary_mtime`, with
`PASS omp_binary_sha256 bf1e86a9…` and `PASS opencode_binary_sha256 d9123b9b…` (canonical/merged
text; p1 `DRIFT` row, rc 1). Substrate-side (fake home): byte-identical omp, only mtime moved
+1 s → `FAIL omp_binary_mtime … live=2026-10-16T08:15:12.226207+00:00`, both sha pins PASS, rc 1.
This is the executable proof of P4's decision: a sha256-only guard is green here; the mtime pin
is what detects the rewrite. 1 s ≫ the 2000 ns device tolerance, so this is a real drift, not a
tolerance artefact (850 ns residue of the live pin is unaffected).

**F2 — unparseable mtime string: all clean, codes differ 2 / 1 / 3.**
canonical rc **2**: `ENVIRONMENT omp_binary_mtime: unparseable pin 'garbage': Invalid isoformat
string: 'garbage'`. p1 rc **1**: `omp_binary_mtime PIN_ABSENT expect='garbage'
observed='1792138511226207850' Invalid isoformat string: 'garbage'` — the pin is *present*; the
verdict is a lie. merged rc **3**: `BAD_BASELINE /tmp/d23/v2/b-garbage.json: omp_binary_mtime:
unparseable pin 'garbage': …`. No tracebacks anywhere; every run names the pin.

**F2-argument — 3 is more honest than 2.** (i) Family text: `verifiers/verify_surfaces.py:107-109`
defines exit **2** as “environment unreadable (binary, dump file, strings tool, inventory file,
or an OS-level baseline *read* error)” and exit **3** as “baseline missing or unparseable (bad
JSON, **missing keys, malformed class id**)”. A malformed pin *value* is the content class
(“malformed class id” is its exact analogue), not an I/O or environment failure. (`harness:28-30`
and `integrity:82-85` use 3 more narrowly — absent-only — so the family is not uniform; surfaces,
the closest analog, is explicit.) (ii) Remedy asymmetry: a missing binary is repaired in the
environment; a garbage pin is repaired by *re-recording it in the baseline* — the exit-3 remedy
(P8 §2b, P1 spec). (iii) Internal consistency: canonical's own message names a *pin* while wearing
an `ENVIRONMENT` banner — a 3-message with a 2-code. (iv) The round-23 claim already binds (d)
corrupt baseline JSON → 3; a garbage value one level deeper must not split into a different code
for the same remedy. Conclusion: **land the merged mapping (3)**; if the integrator keeps 2 they
must accept the banner contradiction above. Note the claim is silent on this exact case, so this
is the one exit-code cell V2 owns.

**F3 — non-string (int) pin: canonical still crashes; merged closes it.** canonical rc 1 with
`TypeError: expected string or bytes-like object, got 'int'` at `/tmp/check_substrate_pins.py:59`
(raised from `:95`, uncaught by the `ValueError`-only handler at `:94-97`) — P7-C1 / P6-D1 class
reproduced. p1 rc 1 but mislabels `DRIFT expect=12345`. merged rc 3 clean
(`BAD_BASELINE … pin is not a string: 12345`).

**F4 — silent shrink reproduced in canonical, closed by p1 and merged.** Deleting the
`omp_binary_mtime` pin: canonical rc **0** `OK 2/2 pins hold` (P7-C9); p1 rc 1 `PIN_ABSENT`;
merged rc 1 `FAIL omp_binary_mtime pin absent from measured_against` + `DRIFT 1/3`. Presence
enforcement (fixed expected-pin set, kept alongside generic stray-key discovery) closes the class
the round-23 dispatch marks MUST-close.

**F5 — null/deleted `measured_against` (M6-D2 class).** canonical: null → traceback rc 1
(`TypeError: 'NoneType' object is not iterable`, `:80`), deleted → `VACUOUS` rc 2. p1: both → rc
3 NO_BASELINE. merged: both → rc **1**, `DRIFT 3/3 … pin absent` — matches claim (e)'s “missing/
null measured_against -> exit 1”. Divergence p1(3) vs claim(1) recorded, not adjudicated here.

**F6 — offset-less pin is silently reinterpreted by canonical.** `b-naive` (no `-03:00`):
canonical assumes UTC (`:62-64`) and reports a 3-hour `DRIFT` naming the pin (`FAIL … live=
2026-10-16T08:15:11.226207+00:00`) — a malformed pin misdiagnosed as substrate movement. p1:
`PIN_ABSENT … has no UTC offset`. merged: rc 3 (offsetless pins rejected as baseline errors).

**F7 — merged JSON error paths have no envelope** (inherited P7-C4, out of V2 scope):
`--json` on `b-garbage` → rc 3, stdout empty, diagnosis on stderr only.

Net for the integrator: the merged draft now satisfies the round-23 claim's six red probes
