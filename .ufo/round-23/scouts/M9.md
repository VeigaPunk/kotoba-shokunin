## Findings

**F1 — The F8 acceptance bar is real and causally identified.** Live 0/1504
exit 0; the same self-test in a `.git`-less `git archive` export: 108 failures /
1504 assertions, exit 1, 70 distinct case ids (cmd 6). One empty `.git`
directory restores 0/1504 exit 0 (cmd 7), so the failure is the `.git`-marker
repo-root fallback, not missing content: the export carries every tracked
fixture (`verifiers/fixtures/checklist/...`). This is exactly the bar the new
script must clear by construction, because its self-test must not depend on a
checkout layout.

**F2 — Both D-drafts clear the bar: `--self-test` is green with no `.git`.**
V4b: `0 failure(s) over 16 assertions`, exit 0, in the export — also from a
subdirectory cwd, from `/tmp`, and with `HOME` pointing at a nonexistent dir
(cmds 9, 11, 12). D5: `0 failure(s) over 11 assertions`, exit 0, same three
variants (cmds 10–12). The mechanism is that both self-tests drive the CLI
surface against `tempfile`-scoped fixtures with explicit `--baseline` /
`--omp-binary` / `--opencode-binary`, so no `.git`, no `$HOME` and no repo tree
is consulted. Acceptance verdict: **met by both drafts**; V4b additionally
proves the point by surviving the same layout that reds the checklist gate
(cmd 6 vs cmd 9 in one directory).

**F3 — Best D-draft is V4b, but it has one landing blocker my probe found:
the default `--repo` is the script's own directory.** `V4b:129`
(`--repo default=Path(__file__).resolve().parent`, help text "repo root") plus
`:144` (`Path(args.repo)/"verifiers"/baseline.json`) resolves to
`<repo>/verifiers/verifiers/baseline.json`. Evidence: bare run in the export →
exit 3 ENOENT on that doubled path (cmd 14); same in a `/tmp` copy placed at
`verifiers/` (cmd 16); with `--baseline verifiers/baseline.json` → `OK 3/3
pins hold`, exit 0 (cmd 15). The round's counting command is the **bare**
`python3 verifiers/check_substrate_pins.py`, so as snapshotted (sha 0510602e…)
the merged draft would land red on its own acceptance run. One-line fix:
`Path(__file__).resolve().parent.parent` (the P1 spec value, and the value the
D5 draft already uses at `D5:63`).

**F4 — The self-test cannot catch F3: it never exercises the default path.**
Both self-tests always pass `--baseline` explicitly (V4b:237; D5's `run()`),
and neither asserts a bare/default-repo invocation. A green `--self-test`
therefore coexists with a broken counting command — the exact "instrument that
cannot see its own default" gap. The landing round must add one assertion that
runs the CLI with no `--baseline` (or with `--repo <export>`), or the defect
class recurs silently.

**F5 — D5 clears the bar by default but is weaker on semantics where the merge
specified V4b's choices.** (a) mtime compare is ns-exact with no tolerance
(`D5:56`): a microsecond-truncated pin (`.226207` vs live `.226207850`) →
`DRIFT`, exit 1 (false positive), while V4b's 2000 ns tolerance passes it
(round-22 P1 L1 class, re-confirmed in the export). (b) A non-string pin
(`12345`) is reported `UNREADABLE` → **exit 2** ("environment"), conflating a
baseline-config error with an unreadable binary; V4b names it and exits 3.
(c) Top-level JSON list and `measured_against: []` → `VACUOUS`, **exit 1**;
V4b maps both to exit 3 (family ladder). No tracebacks in either.

**F6 — The two must-close classes are closed in both drafts (in the export
layout).** Silent-shrink: deleting `omp_binary_mtime` → `PIN_ABSENT
omp_binary_mtime`, exit 1 in both (V4b and D5), while the sha/mtime of the
remaining pins still print — the P7-C9 class is closed. TypeError: `12345` pin
→ no traceback in either (V4b exit 3 named; D5 exit 2 as above). Corrupt JSON →
3, absent baseline → 3, `measured_against: null` → 1 `VACUOUS`, missing binary →
2, sha drift → 1, mtime +1 ns → 1; JSON mode returns the same exit code in the
error envelope (`exit_code` present in both drafts' JSON).

**F7 — Read-only and hash-never-exec hold under the export layout.** The
canary (an executable shell script whose body touches `/tmp/m9/CANARY_FIRED`)
was hashed as the "omp binary": the marker never appeared for either script
(cmd 18). Baseline sha256 unchanged before/after the whole battery (cmd 20);
`find -newer` shows zero files written inside the export and no `__pycache__`
(cmd 21). Deterministic JSON stdout across two runs (cmd 19).

**F8 — Environment fidelity of the probe.** The export contains only tracked
content at 5a33c3e (incl. tracked `.ufo/round-22`), no `.git`, and no
`/tmp/.git` or `/.git` above it (cmd 4). Leftover `/tmp/pins-selftest-*` dirs
exist (e.g. `/tmp/pins-selftest-b-8odfo9q3`, mtime 01:29:28) but pre-date this
run (01:59+) — they are round-22 P4-prototype leakage (P7 F3), not this lane's.

  layouts; no large-file hashing timing.
- The checklist-gate fix for F8 itself was not designed or landed — only the bar
