- **Only the corpus class set was re-derived.** The pin guard is not landed and I did
  not build or fix one (P1–P8 own spec, fixtures, merge recipe); my D3/D4 evidence is
  the round-22 `/tmp` prototype run as-is, on mutated baseline copies only.
- **Agreement is demonstrated on two real trees, not by fuzzing.** My instrument was
  not cross-checked against either in-repo instrument on synthetic fixtures, so a
  shared misreading of the spec on unexercised shapes (nested braces, `~user`,
  odd-quote lines, glob-bearing tokens) would be invisible here.
- **The landing simulation models one artifact shape** (script + 1 fixture dir + 1
  corpus doc + 1 README row, with and without report citations). Other shapes (a
  `.json` companion, two corpus files, fixtures under `corpus/`) move `tracked_files`
  to 54/55 and were not enumerated.
- **Sibling gates were only isolated on copies outside the repo.** The checklist gate
  is relocation-sensitive (its `../` citation checks cannot pass from `/tmp`), so I
  compared pristine vs simulated failure sets rather than asserting a green landing;
  the fault-injection harness was not run this slice, and the harness gate was run
  only against the live tree (28/28).
- **W0 was rebuilt as a `git worktree` of a `/tmp` clone**; I did not re-run the
  round-12-era world (`633859f`) or the tmpfs hermeticity probe, and the round-12 §2
  comparison states remain unverified.
- **No live mutation:** all probes on `/tmp` copies; the live tree's only untracked
