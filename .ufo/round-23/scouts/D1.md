## Findings

### F1 — The merged design, as built (the deliverable)

Namespace/CLI (P1 spec, P3 contract, P8 landing name): `--repo` (default
`Path(__file__).resolve().parent.parent`), `--baseline` (default
`<repo>/verifiers/baseline.json`), `--omp-binary`/`--opencode-binary` (surfaces spelling,
absolute host defaults), `--self-test`, `--json`. Declared pin table
`omp_binary_sha256`, `omp_binary_mtime`, `opencode_binary_sha256`; sha compare
case-insensitive over 64 hex; **mtime ns-exact** via `st_mtime_ns` vs an integer-arithmetic
`parse_iso_ns` (fraction digits integer, `calendar.timegm`; the `fromisoformat`/`.timestamp()`
path is 874 ns low on the live pin — cmd 4 shows `delta_ns=+0` for the faithful parse).

Exit ladder (P1): 0 all match | 1 DRIFT or PIN_ABSENT, each named on its line and in the
summary | 2 binary unreadable (ENOENT/EACCES/EISDIR via `OSError`, and a non-regular file
refused before any measurement) | 3 baseline absent/unparseable/no `measured_against`
object/malformed pin. Precedence 3 > 2 > 1 > 0; `--json` always returns the same code
(cmd 14) and on load errors emits the family envelope `{"checks":[…],"error":…,
"exit_code":3,"fail":N,"pass":N}` (P7 C4 closed; observed key set
`['checks','error','exit_code','fail','pass']`).

Closures, each with its differential evidence:

- **P7 C9 silent shrink → closed.** The three declared pins are mandatory; a missing one
  is `PIN_ABSENT` exit 1 naming it (cmd 13). Canonical P5 on the *same* file exits 0 with
  `OK 2/2 pins hold` (cmd 16) — the defect is reproduced and killed side by side.
- **P6 D1 TypeError → closed.** `measured_against` non-dict (null/int/str/absent) →
  `NO_BASELINE` exit 3, no traceback (cmd 12; canonical P5 tracebacks with exit 1 on the
  same file, cmd 17). Also closed: P7 C1 non-string pin values, P1 L2 (present-but-invalid
  mtime pin was mislabelled `PIN_ABSENT`; now `BAD_PIN` exit 3), P1 L3 / P6's
  silent-coverage boundary (undeclared pins with a known subject are discovered and
  enforced; unknown subject / typo keys are rejected at load, exit 3).
- **P7 C3/C4 exit-code divergence → resolved toward the family**: baseline errors are 3
  (`verify_harness_claims.py:28-30`, `verify_surfaces.py:107-109`,
  `verify_corpus_integrity.py:82-85`), and JSON error paths carry code + envelope.
- **P4 F3 leak → closed**: `TemporaryDirectory`, no scratch dirs (cmd 20).
- **P7 C5/C6 → closed**: docstring declares read-only/deterministic and carries a
  documented-limits section.
- **L4/L5 (self-test quality) → closed**: the self-test runs the CLI surface in-process
  (`run_capture(argv)` → `(code, stdout, stderr)`, `redirect_stdout`+`redirect_stderr`),
  84 assertions, and the F2 trap is encoded three ways (baked-ns literal, tz-equivalence,
  6-digit pin `== CLEAN_NS - 789`). Case C stages a **+1 ns** drift and asserts
  `delta_ns=+1`; case C2 asserts a µs-truncated pin reds. All egress checked: no
  `Traceback` token in any self-test world.

Decisions taken where lane specs conflict (recorded, not silently resolved):

1. **ns-exact kept, canonical's 2000 ns tolerance dropped** — the round-23 claim says
   "mtime ns-exact for omp only", the live pin is 9-digit and matches exactly
   (`delta_ns=+0`), so tolerance would only mask a µs-precision re-pin. Consequence
   documented in the docstring: re-pins must be written from `st_mtime_ns`.
2. **No `--check`/`pins.*` check ids** (P3 had them; P1's spec and canonical P5 did not).
   P1's per-pin line shape is used, with the P3 `pins.declared` information preserved as a
   summary suffix `(free-text keys ignored: …)` so silently-skipped prose stays visible.
3. **Line shape `VERDICT <pin> <detail>`** (not P1's literal `<pin> <VERDICT>`), matching
   the family `PASS/FAIL <id>: <detail>` (`verify_surfaces.py:1054`) and the landing
   plan's expected `DRIFT omp_binary_sha256` (P8 F2e). All red probes name the pin either
   way; if the landing round prefers P1's literal order it is a one-line change.
4. **Name kept** `check_substrate_pins.py` (P8's landing plan fixes it; P1 F5's
   `verify_*` recommendation overridden deliberately — flagged for the landing round).
5. **Fixture dependency**: the self-test reads committed `fixtures/pins/mini.bin` next to
   the script and fails loudly (1 failure, exit 1) if absent (cmd 21).
